# Attio

Give agents tools to search and update CRM records, notes, tasks, and lists in Attio through Mastra Connect. Attio serves these tools from a hosted Model Context Protocol (MCP) server. Your application never stores Attio credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add attio-mcp
```

The CLI guides you through Attio's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `attio-mcp` provider:

```typescript title="src/mastra/agents/attio-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const attioMcpAgent = new Agent({
  id: 'attio-mcp-agent',
  name: 'Attio agent',
  instructions: 'You help people search and update CRM records, notes, tasks, and lists in Attio.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['attio-mcp'] }),
})
```

Mastra discovers Attio's tools from its MCP server when the agent runs. The available tools depend on the server and the connected account, not on your `@mastra/connect` version. Tool keys start with `attio-mcp_`.

To see which tools Attio provides, read the [Attio MCP](https://docs.attio.com/mcp/overview) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
