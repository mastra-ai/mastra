# Clay

Give agents tools to find and research people and companies and run workflows in Clay through Mastra Connect. Clay serves these tools from a hosted Model Context Protocol (MCP) server. Your application never stores Clay credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add clay-mcp
```

The CLI guides you through Clay's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `clay-mcp` provider:

```typescript title="src/mastra/agents/clay-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const clayMcpAgent = new Agent({
  id: 'clay-mcp-agent',
  name: 'Clay agent',
  instructions: 'You help people find and research people and companies and run workflows in Clay.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['clay-mcp'] }),
})
```

Mastra discovers Clay's tools from its MCP server when the agent runs. The available tools depend on the server and the connected account, not on your `@mastra/connect` version. Tool keys start with `clay-mcp_`.

To see which tools Clay provides, read the [MCP in Clay](https://university.clay.com/docs/mcp-settings) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
