# Jira

Give agents tools to search, create, update, and transition issues, and manage comments, worklogs, and issue links in Jira through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores Jira credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add jira
```

The CLI guides you through Jira's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `jira` provider:

```typescript title="src/mastra/agents/jira-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const jiraAgent = new Agent({
  id: 'jira-agent',
  name: 'Jira agent',
  instructions:
    'You help people search, create, update, and transition issues, and manage comments, worklogs, and issue links in Jira.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['jira'] }),
})
```

The agent gets 38 Jira tools, with keys such as `jira_add_comment`. See [Jira tools](/reference/connect/providers#jira) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
