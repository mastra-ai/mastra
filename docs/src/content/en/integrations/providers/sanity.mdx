# Sanity

Give agents tools to query, create, and update content documents in Sanity through Mastra Connect. Sanity serves these tools from a hosted Model Context Protocol (MCP) server. Your application never stores Sanity credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add sanity-mcp
```

The CLI guides you through Sanity's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `sanity-mcp` provider:

```typescript title="src/mastra/agents/sanity-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const sanityMcpAgent = new Agent({
  id: 'sanity-mcp-agent',
  name: 'Sanity agent',
  instructions: 'You help people query, create, and update content documents in Sanity.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['sanity-mcp'] }),
})
```

Mastra discovers Sanity's tools from its MCP server when the agent runs. The available tools depend on the server and the connected account, not on your `@mastra/connect` version. Tool keys start with `sanity-mcp_`.

To see which tools Sanity provides, read the [Sanity MCP server](https://www.sanity.io/docs/ai/mcp-server) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
