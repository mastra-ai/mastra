# Fireflies.ai

Give agents tools to read meeting transcripts and analytics, ask questions about meetings, create soundbites, and manage meeting sharing and privacy in Fireflies.ai through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores Fireflies.ai credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add fireflies
```

The CLI guides you through Fireflies.ai's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `fireflies` provider:

```typescript title="src/mastra/agents/fireflies-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const firefliesAgent = new Agent({
  id: 'fireflies-agent',
  name: 'Fireflies.ai agent',
  instructions:
    'You help people read meeting transcripts and analytics, ask questions about meetings, create soundbites, and manage meeting sharing and privacy in Fireflies.ai.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['fireflies'] }),
})
```

The agent gets 27 Fireflies.ai tools, with keys such as `fireflies_add_to_live`. See [Fireflies.ai tools](/reference/connect/providers#firefliesai) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
