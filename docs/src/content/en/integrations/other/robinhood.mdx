# Robinhood

Give agents tools to read account and market data and place trades in Robinhood through Mastra Connect. Robinhood serves these tools from a hosted Model Context Protocol (MCP) server. Your application never stores Robinhood credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

:::warning

These tools can place real trades with real money. Require approval for trading tools with `requireApproval` so a person confirms each order before it runs. See [MCP providers](/reference/connect/tools#mcp-providers).

:::

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add robinhood-mcp
```

The CLI guides you through Robinhood's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `robinhood-mcp` provider:

```typescript title="src/mastra/agents/robinhood-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const robinhoodMcpAgent = new Agent({
  id: 'robinhood-mcp-agent',
  name: 'Robinhood agent',
  instructions: 'You help people read account and market data and place trades in Robinhood.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['robinhood-mcp'] }),
})
```

Mastra discovers Robinhood's tools from its MCP server when the agent runs. The available tools depend on the server and the connected account, not on your `@mastra/connect` version. Tool keys start with `robinhood-mcp_`.

To see which tools Robinhood provides, read the [Agentic Trading](https://robinhood.com/us/en/support/agentic-trading) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
