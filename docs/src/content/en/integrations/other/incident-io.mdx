# incident.io

Give agents tools to create and update incidents, manage follow-ups and actions, and read alerts, schedules, and catalog entries in incident.io through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores incident.io credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add incident-io
```

The CLI guides you through incident.io's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `incident-io` provider:

```typescript title="src/mastra/agents/incident-io-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const incidentIoAgent = new Agent({
  id: 'incident-io-agent',
  name: 'incident.io agent',
  instructions: 'You help people create and update incidents, manage follow-ups and actions, and read alerts, schedules, and catalog entries in incident.io.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['incident-io'] }),
})
```

The agent gets 66 incident.io tools, with keys such as `incident_io_add_alert_tags`. See [incident.io tools](/reference/connect/providers#incidentio) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
