# Figma

Give agents tools to read files, versions, components, and styles, render images, and manage comments and dev resources in Figma through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores Figma credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

:::note

Dev resource tools need Dev Mode, which needs a paid Figma plan and a Full or Dev seat. Node IDs work in either the `1:2` form the API uses or the `1-2` form in Figma URLs. The toolset can't list a team's projects or files, so give the agent a file key or file URL.

:::

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add figma
```

The CLI guides you through Figma's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `figma` provider:

```typescript title="src/mastra/agents/figma-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const figmaAgent = new Agent({
  id: 'figma-agent',
  name: 'Figma agent',
  instructions:
    'You help people read files, versions, components, and styles, render images, and manage comments and dev resources in Figma.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['figma'] }),
})
```

The agent gets 26 Figma tools, with keys such as `figma_create_comment`. See [Figma tools](/reference/connect/providers#figma) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
