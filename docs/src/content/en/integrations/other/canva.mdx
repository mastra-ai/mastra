# Canva

Give agents tools to create, edit, search, and export designs in Canva through Mastra Connect. Canva serves these tools from a hosted Model Context Protocol (MCP) server. Your application never stores Canva credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add canva-mcp
```

The CLI guides you through Canva's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `canva-mcp` provider:

```typescript title="src/mastra/agents/canva-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const canvaMcpAgent = new Agent({
  id: 'canva-mcp-agent',
  name: 'Canva agent',
  instructions: 'You help people create, edit, search, and export designs in Canva.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['canva-mcp'] }),
})
```

Mastra discovers Canva's tools from its MCP server when the agent runs. The available tools depend on the server and the connected account, not on your `@mastra/connect` version. Tool keys start with `canva-mcp_`.

To see which tools Canva provides, read the [Canva MCP](https://www.canva.dev/docs/apps/mcp/) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
