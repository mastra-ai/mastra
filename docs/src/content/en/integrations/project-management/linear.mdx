# Linear

Give agents tools to search, create, and update issues, and manage projects, cycles, comments, and labels in Linear through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores Linear credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add linear
```

The CLI guides you through Linear's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `linear` provider:

```typescript title="src/mastra/agents/linear-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const linearAgent = new Agent({
  id: 'linear-agent',
  name: 'Linear agent',
  instructions: 'You help people search, create, and update issues, and manage projects, cycles, comments, and labels in Linear.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['linear'] }),
})
```

The agent gets 46 Linear tools, with keys such as `linear_add_issue_label`. See [Linear tools](/reference/connect/providers#linear) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
