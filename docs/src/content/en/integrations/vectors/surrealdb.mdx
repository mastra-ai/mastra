# SurrealDB vector store

The `SurrealVector` class provides vector search in [SurrealDB](https://surrealdb.com). Each index is a table whose `embedding` field has an HNSW index; queries run as SurrealQL nearest-neighbour searches with the metadata filter applied during the search, so a selective filter still returns `topK` matches.

## Installation

```bash npm2yarn
npm install @mastra/surrealdb@latest
```

## Usage example

```typescript
import { SurrealVector } from '@mastra/surrealdb'

const store = new SurrealVector({
  id: 'surrealdb-vector',
  url: process.env.SURREALDB_URL!,
  username: process.env.SURREALDB_USERNAME!,
  password: process.env.SURREALDB_PASSWORD!,
  namespace: 'mastra',
  database: 'my_app',
})

await store.createIndex({ indexName: 'docs', dimension: 1536 })

await store.upsert({
  indexName: 'docs',
  vectors: embeddings,
  metadata: chunks.map(chunk => ({ text: chunk.text, source: 'faq' })),
})

const results = await store.query({
  indexName: 'docs',
  queryVector,
  topK: 5,
  filter: { source: 'faq' },
})
```

`SurrealVector` and `SurrealDBStore` can share one connection:

```typescript
import { SurrealDBStore, SurrealVector } from '@mastra/surrealdb'

const storage = new SurrealDBStore({ id: 'surrealdb-storage', url, username, password })
const vector = new SurrealVector({ id: 'surrealdb-vector', connector: storage.connector })
```

## Methods

### `createIndex()`

Creates a table for the index and an HNSW index on its `embedding` field. Creating an index that already exists with the same dimension does nothing.

Scores are `1 - distance` for cosine, `1 / (1 + distance)` for euclidean and the dot product for `dotproduct`.

### `describeIndex()`

Returns the dimension, metric and vector count of an index.

```typescript
const { dimension, metric, count } = await store.describeIndex({ indexName: 'docs' })
```

### `listIndexes()`

Returns the names of every index created by `SurrealVector`.

### `deleteIndex()`

Removes the index and its table. Deleting an index that doesn't exist does nothing.

### `updateVector()`

Updates the vector and/or metadata of one vector by `id`, or of every vector matching `filter`.

```typescript
await store.updateVector({
  indexName: 'docs',
  id: 'doc-1',
  update: { metadata: { source: 'faq' } },
})
await store.updateVector({
  indexName: 'docs',
  filter: { source: 'draft' },
  update: { metadata: { source: 'faq' } },
})
```

### `deleteVector()`

Deletes one vector by `id`.

### `deleteVectors()`

Deletes vectors by `ids`, or every vector matching `filter`.

```typescript
await store.deleteVectors({ indexName: 'docs', filter: { source: 'draft' } })
```

### `disconnect()`

Closes the connection when the vector store opened it.

## Metadata filtering

Filters use MongoDB-style operators: `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte`, `$in`, `$nin`, `$all`, `$elemMatch`, `$size`, `$exists`, `$regex`, `$contains`, `$and`, `$or`, `$nor` and `$not`. Nested fields use dot notation. Field names and values are always passed to SurrealDB as query parameters.

```typescript
const results = await store.query({
  indexName: 'docs',
  queryVector,
  topK: 10,
  filter: {
    $and: [
      { category: { $in: ['guides', 'faq'] } },
      { 'author.team': 'docs' },
      { tags: { $all: ['public'] } },
    ],
  },
})
```

`SURREALDB_PROMPT` describes the supported operators for agents that build filters with the vector query tool.
