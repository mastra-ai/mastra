# Microsoft Outlook

Give agents tools to read, send, draft, and reply to email, manage mail folders, and create and update calendar events in Microsoft Outlook through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores Microsoft Outlook credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add outlook
```

The CLI guides you through Microsoft Outlook's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `outlook` provider:

```typescript title="src/mastra/agents/outlook-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const outlookAgent = new Agent({
  id: 'outlook-agent',
  name: 'Microsoft Outlook agent',
  instructions:
    'You help people read, send, draft, and reply to email, manage mail folders, and create and update calendar events in Microsoft Outlook.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['outlook'] }),
})
```

The agent gets 30 Microsoft Outlook tools, with keys such as `outlook_add_event_attachment`. See [Microsoft Outlook tools](/reference/connect/providers#microsoft-outlook) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
