# Google Calendar

Give agents tools to find, create, and update events, check availability, and manage calendars in Google Calendar through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores Google Calendar credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add google-calendar
```

The CLI guides you through Google Calendar's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `google-calendar` provider:

```typescript title="src/mastra/agents/google-calendar-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleCalendarAgent = new Agent({
  id: 'google-calendar-agent',
  name: 'Google Calendar agent',
  instructions: 'You help people find, create, and update events, check availability, and manage calendars in Google Calendar.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-calendar'] }),
})
```

The agent gets 43 Google Calendar tools, with keys such as `google_calendar_add_attendee`. See [Google Calendar tools](/reference/connect/providers#google-calendar) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
