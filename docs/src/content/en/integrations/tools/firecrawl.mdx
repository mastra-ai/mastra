# Firecrawl

The `@mastra/firecrawl` package exposes [Firecrawl Search](https://docs.firecrawl.dev/features/search) and [Scrape](https://docs.firecrawl.dev/features/scrape) as Mastra-compatible tools. Each factory returns a tool created with [`createTool()`](/reference/tools/create-tool) and a typed Zod input and output schema.

## Installation

```bash npm2yarn
npm install @mastra/firecrawl firecrawl zod
```

Set `FIRECRAWL_API_KEY` in your environment. You can also pass an API key directly to any factory.

## Quick start

Use `createFirecrawlTools()` to create both tools with shared client configuration:

```typescript title="src/mastra/tools/index.ts"
import { createFirecrawlTools } from '@mastra/firecrawl'

export const firecrawlTools = createFirecrawlTools()
// Or pass an explicit API key:
// export const firecrawlTools = createFirecrawlTools({ apiKey: 'fc-api-key' })
```

The returned object contains `firecrawlSearch` and `firecrawlScrape`.

Create either tool separately when an agent doesn't need both:

```typescript title="src/mastra/tools/index.ts"
import { createFirecrawlScrapeTool, createFirecrawlSearchTool } from '@mastra/firecrawl'

export const searchTool = createFirecrawlSearchTool()
export const scrapeTool = createFirecrawlScrapeTool({ apiKey: 'fc-api-key' })
```

The client isn't initialized until the tool executes. A missing API key therefore fails at execution time with a configuration error.

## `createFirecrawlSearchTool()`

Creates the `firecrawl-search` tool. Search returns web, news and image results for a query and can optionally scrape each web result into Markdown in the same call.

```typescript
import { createFirecrawlSearchTool } from '@mastra/firecrawl'

const searchTool = createFirecrawlSearchTool()
```

## Use the tools with an agent

```typescript title="src/mastra/agents/research-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createFirecrawlTools } from '@mastra/firecrawl'

export const researchAgent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'Search the web for current sources, then scrape the most relevant pages for details.',
  tools: createFirecrawlTools(),
})
```
