# Anthropic

Give agents tools to send messages, count tokens, run message batches, read models, and manage files in Anthropic through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores Anthropic credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add anthropic
```

The CLI guides you through Anthropic's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `anthropic` provider:

```typescript title="src/mastra/agents/anthropic-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const anthropicAgent = new Agent({
  id: 'anthropic-agent',
  name: 'Anthropic agent',
  instructions:
    'You help people send messages, count tokens, run message batches, read models, and manage files in Anthropic.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['anthropic'] }),
})
```

The agent gets 12 Anthropic tools, with keys such as `anthropic_cancel_message_batch`. See [Anthropic tools](/reference/connect/providers#anthropic) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
