# Keenable

The `@mastra/keenable` package wraps the [Keenable API](https://docs.keenable.ai/api-reference) as Mastra-compatible tools for web search and page fetching. It exposes factory functions that return tools created with [`createTool()`](/reference/tools/create-tool) and full Zod input/output schemas.

The tools work without an API key. Keyless requests use Keenable's public endpoints, which are rate limited. An API key from the [Keenable console](https://keenable.ai/console) raises the limit.

## Installation

Install the package alongside Zod:

```sh npm2yarn
npm install @mastra/keenable zod
```

## Usage example

The following example creates both tools with the default configuration. When `KEENABLE_API_KEY` is set in the environment, the tools use it. Without it, they use the keyless endpoints.

```typescript title="src/mastra/tools/index.ts"
import { createKeenableTools } from '@mastra/keenable'

const { keenableSearch, keenableFetch } = createKeenableTools()
```

To pass an API key explicitly:

```typescript title="src/mastra/tools/index.ts"
import { createKeenableTools } from '@mastra/keenable'

const tools = createKeenableTools({ apiKey: 'keen_...' })
```

## Methods

### Factory functions

#### `createKeenableTools(config?)`

Returns an object containing all Keenable tools that share the supplied configuration.

```typescript
import { createKeenableTools } from '@mastra/keenable'

const tools = createKeenableTools()
// tools.keenableSearch, tools.keenableFetch
```

Returns: `{ keenableSearch, keenableFetch }`

#### `createKeenableSearchTool(config?)`

Creates a tool that searches the web using the Keenable Search API. Returns ranked results with titles, URLs, page text snippets of about 500 characters, and publication dates when known.

The tool is registered with the ID `keenable-search`.

```typescript
import { createKeenableSearchTool } from '@mastra/keenable'

const searchTool = createKeenableSearchTool()
```

#### `createKeenableFetchTool(config?)`

Creates a tool that reads a web page using the Keenable Fetch API and returns its main content as Markdown.

The tool is registered with the ID `keenable-fetch`.

const fetchTool = createKeenableFetchTool()

## Agent example

The following example registers both tools on an agent so it can search the web and then read the pages it finds.

```typescript title="src/mastra/agents/index.ts"
import { Agent } from '@mastra/core/agent'
import { createKeenableTools } from '@mastra/keenable'

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'You are a research assistant. Use keenable-search to find current sources, then keenable-fetch to read a page before quoting it.',
  tools: createKeenableTools(),
})
```

## Environment variables

| Variable | Description |
| - | - |
| `KEENABLE_API_KEY` | Optional Keenable API key. Used as the default when `apiKey` isn't passed to a factory function. Without it, the tools use the rate-limited keyless endpoints. |
