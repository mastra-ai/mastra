# Ceramic

The `@mastra/ceramic` package exposes [Ceramic Search](https://docs.ceramic.ai/api/search/quickstart) as a Mastra-compatible tool. The factory returns a tool created with [`createTool()`](/reference/tools/create-tool) and a typed Zod input and output schema.

Ceramic is a fast lexical search engine. It matches the words in a query rather than inferring intent, so agents get the best results from specific keyword queries.

## Installation

```bash npm2yarn
npm install @mastra/ceramic ceramic-ai zod
```

Set `CERAMIC_API_KEY` in your environment. You can create a key on the [Ceramic platform](https://platform.ceramic.ai/keys) or pass an API key directly to any factory.

## Quick start

Use `createCeramicTools()` to create the tool set with shared client configuration:

```typescript title="src/mastra/tools/index.ts"
import { createCeramicTools } from '@mastra/ceramic'

export const ceramicTools = createCeramicTools()
// Or pass an explicit API key:
// export const ceramicTools = createCeramicTools({ apiKey: 'ceramic-api-key' })
```

The returned object contains `ceramicSearch`.

You can also create the search tool directly:

```typescript title="src/mastra/tools/index.ts"
import { createCeramicSearchTool } from '@mastra/ceramic'

export const searchTool = createCeramicSearchTool()
```

The client isn't initialized until the tool executes. A missing API key therefore fails at execution time with a configuration error.

## `createCeramicSearchTool()`

Creates the `ceramic-search` tool. Search returns ranked results with titles, URLs, and page content for a keyword query.

```typescript
import { createCeramicSearchTool } from '@mastra/ceramic'

const searchTool = createCeramicSearchTool()
```

## Write effective queries

Ceramic doesn't match synonyms or infer meaning, so the words in the query decide which pages match. The tool description tells agents to follow these practices:

- Rewrite questions into specific keywords. Use `California rental laws` instead of `What are the rental laws in California?`.
- Include alternative terms when a page might use different words, such as `college university tuition costs US`.
- Use `site:` to limit results to one domain, `OR` with parentheses to match either term, and quotation marks to match an exact phrase.
- Run several keyword variations for one request and combine the results. Searches are fast and inexpensive.

Ceramic currently searches English web pages. See the [Ceramic best practices guide](https://docs.ceramic.ai/api/search/best-practices) for more detail.

## Use the tools with an agent

```typescript title="src/mastra/agents/research-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createCeramicTools } from '@mastra/ceramic'

export const researchAgent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'Search the web with specific keyword queries. Try several keyword variations and combine the results before answering.',
  tools: createCeramicTools(),
})
```
