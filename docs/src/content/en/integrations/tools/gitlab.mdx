# GitLab

Give agents tools to manage projects, groups, issues, merge requests, branches, files, commits, and releases, and run, cancel, and retry pipelines and jobs in GitLab through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores GitLab credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add gitlab
```

The CLI guides you through GitLab's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `gitlab` provider:

```typescript title="src/mastra/agents/gitlab-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const gitlabAgent = new Agent({
  id: 'gitlab-agent',
  name: 'GitLab agent',
  instructions:
    'You help people manage projects, groups, issues, merge requests, branches, files, commits, and releases, and run, cancel, and retry pipelines and jobs in GitLab.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['gitlab'] }),
})
```

The agent gets 44 GitLab tools, with keys such as `gitlab_cancel_pipeline`. See [GitLab tools](/reference/connect/providers#gitlab) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
