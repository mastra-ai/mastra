# Google Sheets

Give agents tools to read, append, update, and clear cell values, and create spreadsheets, rows, and worksheets in Google Sheets through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores Google Sheets credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add google-sheet
```

The CLI guides you through Google Sheets' authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `google-sheet` provider:

```typescript title="src/mastra/agents/google-sheet-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleSheetAgent = new Agent({
  id: 'google-sheet-agent',
  name: 'Google Sheets agent',
  instructions:
    'You help people read, append, update, and clear cell values, and create spreadsheets, rows, and worksheets in Google Sheets.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-sheet'] }),
})
```

The agent gets 18 Google Sheets tools, with keys such as `google_sheet_append_values_to_spreadsheet`. See [Google Sheets tools](/reference/connect/providers#google-sheets) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
