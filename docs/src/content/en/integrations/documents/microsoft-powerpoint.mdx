# Microsoft PowerPoint

Give agents tools to find, create, copy, and move presentations, read and update their content, and share them in Microsoft PowerPoint through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores Microsoft PowerPoint credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add microsoft-powerpoint
```

The CLI guides you through Microsoft PowerPoint's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `microsoft-powerpoint` provider:

```typescript title="src/mastra/agents/microsoft-powerpoint-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftPowerpointAgent = new Agent({
  id: 'microsoft-powerpoint-agent',
  name: 'Microsoft PowerPoint agent',
  instructions:
    'You help people find, create, copy, and move presentations, read and update their content, and share them in Microsoft PowerPoint.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-powerpoint'] }),
})
```

The agent gets 18 Microsoft PowerPoint tools, with keys such as `microsoft_powerpoint_copy_presentation`. See [Microsoft PowerPoint tools](/reference/connect/providers#microsoft-powerpoint) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
