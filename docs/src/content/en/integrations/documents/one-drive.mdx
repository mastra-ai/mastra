# OneDrive

Give agents tools to search, upload, copy, move, and share files and folders, and manage permissions and versions in OneDrive through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores OneDrive credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add one-drive
```

The CLI guides you through OneDrive's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `one-drive` provider:

```typescript title="src/mastra/agents/one-drive-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const oneDriveAgent = new Agent({
  id: 'one-drive-agent',
  name: 'OneDrive agent',
  instructions:
    'You help people search, upload, copy, move, and share files and folders, and manage permissions and versions in OneDrive.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['one-drive'] }),
})
```

The agent gets 20 OneDrive tools, with keys such as `one_drive_copy_item`. See [OneDrive tools](/reference/connect/providers#onedrive) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
