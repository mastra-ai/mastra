# Google Docs

Give agents tools to create documents, insert and replace text, and edit tables, headers, footers, and styles in Google Docs through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores Google Docs credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add google-docs
```

The CLI guides you through Google Docs' authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `google-docs` provider:

```typescript title="src/mastra/agents/google-docs-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleDocsAgent = new Agent({
  id: 'google-docs-agent',
  name: 'Google Docs agent',
  instructions:
    'You help people create documents, insert and replace text, and edit tables, headers, footers, and styles in Google Docs.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-docs'] }),
})
```

The agent gets 37 Google Docs tools, with keys such as `google_docs_add_document_tab`. See [Google Docs tools](/reference/connect/providers#google-docs) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
