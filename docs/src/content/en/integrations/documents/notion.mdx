# Notion

Give agents tools to search, read, create, and update pages, append blocks, and query databases and data sources in Notion through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores Notion credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add notion
```

The CLI guides you through Notion's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `notion` provider:

```typescript title="src/mastra/agents/notion-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const notionAgent = new Agent({
  id: 'notion-agent',
  name: 'Notion agent',
  instructions: 'You help people search, read, create, and update pages, append blocks, and query databases and data sources in Notion.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['notion'] }),
})
```

The agent gets 44 Notion tools, with keys such as `notion_append_block_children`. See [Notion tools](/reference/connect/providers#notion) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
