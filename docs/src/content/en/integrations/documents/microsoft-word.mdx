# Microsoft Word

Give agents tools to find, create, copy, and move Word documents, read and update their content, and share them in Microsoft Word through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores Microsoft Word credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add microsoft-word
```

The CLI guides you through Microsoft Word's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `microsoft-word` provider:

```typescript title="src/mastra/agents/microsoft-word-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftWordAgent = new Agent({
  id: 'microsoft-word-agent',
  name: 'Microsoft Word agent',
  instructions:
    'You help people find, create, copy, and move Word documents, read and update their content, and share them in Microsoft Word.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-word'] }),
})
```

The agent gets 18 Microsoft Word tools, with keys such as `microsoft_word_copy_word_document`. See [Microsoft Word tools](/reference/connect/providers#microsoft-word) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
