# SharePoint Online

Give agents tools to search sites and files, manage lists, list items, and site pages, and share drive items in SharePoint Online through Mastra Connect. Each tool call goes through the Mastra platform, which adds the connection's credential. Your application never stores SharePoint Online credentials.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

### Connect an account

Run this command from the directory that contains your `.env` file:

```bash
mastra connect add sharepoint-online
```

The CLI guides you through SharePoint Online's authorization and waits until the connection is active.

### Add tools to an agent

Pass [`tools()`](/reference/connect/tools) to the agent and select the `sharepoint-online` provider:

```typescript title="src/mastra/agents/sharepoint-online-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const sharepointOnlineAgent = new Agent({
  id: 'sharepoint-online-agent',
  name: 'SharePoint Online agent',
  instructions: 'You help people search sites and files, manage lists, list items, and site pages, and share drive items in SharePoint Online.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['sharepoint-online'] }),
})
```

The agent gets 53 SharePoint Online tools, with keys such as `sharepoint_online_add_content_type_to_list`. See [SharePoint Online tools](/reference/connect/providers#sharepoint-online) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
