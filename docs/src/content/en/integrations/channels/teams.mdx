# Microsoft Teams

Use Microsoft Teams with Mastra in two ways:

- **Agent tools** let an agent act in Teams, for example to read and send messages or manage channels.
- **Agent chat** lets people talk to your agent through Teams mentions and conversation events.

[Mastra Connect](/docs/mastra-platform/connect) sets up both and registers the Teams bot for you, so you don't need your own Azure app registration. You can also register the bot and manage its credentials yourself.

## Connect

Before you start, complete the [Connect setup](/docs/mastra-platform/connect#get-started) to install `@mastra/connect` and configure your platform project.

One `microsoft-teams` connection provides both agent tools and agent chat. Sign in with a Microsoft work or school account. Some requested permissions need admin consent, so the first connection in a tenant needs a Microsoft Entra administrator.

### Agent chat

When you connect an agent, Mastra registers a bot for it in the Teams Developer Portal. Mastra stores the bot credential encrypted. Set `MASTRA_ENCRYPTION_KEY` to use a dedicated key. Without it, `channels()` derives a key from the platform access token and logs a warning. If you then rotate the platform access token, Mastra can't read the stored bot credentials. Disconnect and reconnect the channel to create new ones.

Your server needs a public URL for Teams webhooks and OAuth callbacks. Mastra platform supplies this URL. When you host elsewhere, set `MASTRA_SERVER_URL` to your public server URL. For local development, use a public HTTPS tunnel.

1. If you haven't added the connection yet, run `mastra connect add microsoft-teams` and sign in.

1. Pass [`channels()`](/reference/connect/channels) to the `Mastra` constructor. It registers the Teams channel provider and its routes:

   ```typescript title="src/mastra/index.ts"
   import { Mastra } from '@mastra/core'
   import { channels } from '@mastra/connect'
   import { assistant } from './agents/assistant'

   export const mastra = new Mastra({
     agents: { assistant },
     channels: await channels({ providers: ['microsoft-teams'] }),
   })
   ```

   To register other channels too, add their provider IDs to `providers`.

1. Start your Mastra application.

1. In Studio, connect the Teams channel to an agent. Mastra creates a single-tenant bot registration for the agent and returns a link to the [Teams Developer Portal](https://dev.teams.microsoft.com/bots).

1. Open the link, package the bot into a Teams app in the Developer Portal, and add the app to Teams.

Disconnecting the agent deletes the bot registration and its Entra application.

## Self-managed setup

Use the Chat SDK Teams adapter with your own Azure bot registration and credentials.

### Install the adapter

Install the Teams adapter from the Chat SDK:

```bash npm2yarn
npm install @chat-adapter/teams
```

### Agent configuration

Add `createTeamsAdapter()` to the agent's `channels.adapters` object:

```typescript title="src/mastra/agents/teams-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createTeamsAdapter } from '@chat-adapter/teams'

export const teamsAgent = new Agent({
  id: 'teams-agent',
  name: 'Teams Agent',
  instructions: 'Answer questions and help with tasks in Microsoft Teams.',
  model: '__GATEWAY_OPENAI_MODEL__',
  channels: {
    adapters: {
      teams: createTeamsAdapter({
        appType: 'SingleTenant',
      }),
    },
  },
})
```

Register the agent on the Mastra instance:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { teamsAgent } from './agents/teams-agent'

export const mastra = new Mastra({
  agents: { teamsAgent },
})
```

### Adapter setup

Follow the [Chat SDK Teams adapter docs](https://chat-sdk.dev/adapters/official/teams) for Teams-specific setup, including Azure bot registration, Teams CLI usage, authentication options, and required permissions.

The adapter reads Teams credentials from environment variables such as:

```bash title=".env"
TEAMS_APP_ID=your-azure-bot-app-id
TEAMS_APP_PASSWORD=your-azure-bot-app-password
TEAMS_APP_TENANT_ID=your-azure-tenant-id
```

### Webhook URL

Mastra generates the Teams webhook route from the agent ID and adapter key:

```text
/api/agents/teams-agent/channels/teams/webhook
```

Use your public Mastra server URL as the base URL:

```text
https://your-app.example.com/api/agents/teams-agent/channels/teams/webhook
```

Use this URL anywhere the Teams adapter docs ask for the bot endpoint or webhook URL. For local development, expose the Mastra dev server with a tunnel and use the tunnel URL as the base URL.
