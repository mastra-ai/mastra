# Datasets API

The Datasets API exposes Mastra's dataset and experiment routes from `MastraClient`. This page covers the external experiment methods, which let a runner you own (for example a Temporal workflow) use Mastra as the experiment system of record: create an experiment, submit per-item results over HTTP, and finalize when done.

All three methods are safe to retry:

- `createExternalExperiment` is idempotent on a caller-supplied `id`
- `submitExperimentResult` upserts on `(experimentId, itemId, attempt)`
- `finalizeExperiment` returns the stored record if the experiment is already completed

## Usage example

```typescript
import { MastraClient } from '@mastra/client-js'

const client = new MastraClient({
  baseUrl: 'http://localhost:4111',
})

// 1. Create the experiment. Pass your orchestrator's run ID so a
//    retried workflow converges on the same experiment.
const { experimentId, totalItems, datasetVersion } = await client.createExternalExperiment({
  datasetId: 'clinical-triage-evals',
  id: 'temporal-wf-run-42',
  name: 'nightly-eval',
})

// 2. Submit one result per item from your workers. Retried activities
//    converge on a single row per (experimentId, itemId, attempt).
await client.submitExperimentResult({
  datasetId: 'clinical-triage-evals',
  experimentId,
  itemId: 'item-1',
  output: { triage: 'urgent' },
  scores: [{ scorerId: 'clinical-judge', score: 0.92, reason: 'Correct triage level' }],
})

// 3. Finalize. The server computes succeeded/failed/skipped counts
//    from the persisted rows.
const experiment = await client.finalizeExperiment({
  datasetId: 'clinical-triage-evals',
  experimentId,
})
```

## submitExperimentResult()

Submitting to a non-external experiment returns a `400`; submitting after finalization returns a `409`.

## finalizeExperiment()

Marks an external experiment completed. The server computes per-item counts from the persisted result rows — `succeededCount` (at least one attempt without an error), `failedCount` (every attempt errored), `skippedCount` (never submitted) — so the caller keeps no bookkeeping. Idempotent: finalizing an already-completed experiment returns the stored record.

Returns `Promise<DatasetExperiment>` — the updated experiment record.
