# Memory.archiveThread()

The `.archiveThread()` method archives a thread by setting its `archivedAt` timestamp. The thread and its messages are kept, and it can be restored with [`.unarchiveThread()`](/reference/memory/unarchiveThread). Archiving doesn't change the thread's `updatedAt`, so thread ordering stays the same.

Use the `archived` filter on [`.listThreads()`](/reference/memory/listThreads) to include or exclude archived threads.

## Usage example

```typescript
await memory.archiveThread({ threadId: 'thread-123' })
```
