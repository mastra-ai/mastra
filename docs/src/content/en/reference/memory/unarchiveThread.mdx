# Memory.unarchiveThread()

The `.unarchiveThread()` method restores a thread archived with [`.archiveThread()`](/reference/memory/archiveThread) by clearing its `archivedAt` timestamp. Unarchiving doesn't change the thread's `updatedAt`.

## Usage example

```typescript
await memory.unarchiveThread({ threadId: 'thread-123' })
```
