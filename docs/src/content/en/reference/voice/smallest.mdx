# Smallest AI

The SmallestVoice class in Mastra provides text-to-speech using Smallest AI's Waves Lightning models and speech-to-text using their Pulse models.

## Usage example

```typescript
import { SmallestVoice } from '@mastra/voice-smallest'

// Initialize with default configuration using environment variables
const voice = new SmallestVoice()

// Or initialize with specific configuration
const voiceWithConfig = new SmallestVoice({
  speechModel: {
    model: 'lightning_v3.1_pro',
    apiKey: process.env.SMALLEST_API_KEY!,
    language: 'auto',
    sampleRate: 24000,
    speed: 1.0,
    outputFormat: 'wav',
  },
  listeningModel: {
    model: 'pulse',
    apiKey: process.env.SMALLEST_API_KEY!,
    language: 'en',
  },
  speaker: 'meher',
})

// List the voices available on the configured model
const speakers = await voice.getSpeakers()

// Convert text to speech
const audioStream = await voice.speak('Hello, how can I help you?')

// Convert speech to text
const text = await voice.listen(createReadStream('./audio.wav'))
```

### `getSpeakers()`

Returns the voices available on the configured model, each with its display name and descriptive tags (language, accent, gender, age, use cases).

Returns: `Promise<Array<{voiceId: string, displayName?: string, tags?: SmallestVoiceTags}>>`

## Notes

- API key can be provided via constructor options or the `SMALLEST_API_KEY` environment variable
- If no API key is provided, the constructor will throw an error
- The service communicates with the Smallest AI API at `https://api.smallest.ai/waves/v1`
- Audio is returned as a stream containing binary audio data
- `speak()` accepts at most 250 characters per request, which is the model's own limit. Split longer replies on sentence boundaries and speak each segment in order — this also lowers time-to-first-audio in a live agent
- Voice IDs are not interchangeable between `lightning_v3.1` and `lightning_v3.1_pro`. Pairing a voice with the wrong pool produces unintelligible audio rather than an error, so resolve IDs with `getSpeakers()` on the model you configured
- Cloned voices are only supported on the `lightning_v3.1` pool
- Smallest AI caps concurrent text-to-speech requests per account and answers the overflow with a 429, which is worth retrying with backoff
