# ClassifierProcessor

The `ClassifierProcessor` is a hybrid processor that runs a [`Classifier`](/reference/classifier/classifier) over message text and applies a `decide` policy to the typed answers. The classifier provides evidence such as probabilities, choices, and scores. The `decide` function owns application policy: it returns `pass`, `block`, or `filter`.

Block reasons are always the string supplied by the caller. Provider-generated text is never included in the abort message.

## Usage example

```typescript
import { Classifier } from '@mastra/core/classifier'
import { ClassifierProcessor, decisions } from '@mastra/core/processors'

const safety = new Classifier({
  id: 'safety',
  model,
  questions: {
    unsafe: {
      type: 'boolean',
      criteria: { true: 'The message is unsafe', false: 'The message is safe' },
    },
  },
})

const processor = new ClassifierProcessor({
  classifier: safety,
  decide: decisions.blockIf('unsafe', {
    probability: 0.8,
    reason: 'Message rejected by safety policy',
  }),
  lastMessageOnly: true,
})
```

## Decisions

`decide` returns one of:

- `{ action: 'pass' }` — content continues unchanged.
- `{ action: 'block', reason }` — the request is aborted with a tripwire using `reason`.
- `{ action: 'filter' }` — the offending message or stream chunk is dropped.

| Phase | `pass` | `block` | `filter` |
| - | - | - | - |
| `input` | messages pass | abort before the LLM | message removed |
| `output` | messages pass | abort the response | message removed |
| `stream` | chunk emitted | abort the stream | chunk not emitted |

Messages with no text content are passed through without calling the classifier.

## `decisions` helpers

`decisions` builds typed `decide` functions for common policies. Question keys and choice options are narrowed from the classifier's question map, so mismatched shapes are compile errors.

Every helper accepts `reason` and an optional `action` (`'block'` by default, or `'filter'`).

## Extended usage examples

### Topic scoping with `blockUnless`

```typescript title="src/mastra/agents/support-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Classifier } from '@mastra/core/classifier'
import { ClassifierProcessor, decisions } from '@mastra/core/processors'

const topic = new Classifier({
  id: 'topic',
  model,
  questions: {
    topic: {
      type: 'choice',
      criteria: {
        billing: 'Questions about invoices or payments',
        account: 'Questions about account settings',
        other: 'Anything else',
      },
    },
  },
})

export const agent = new Agent({
  id: 'support-agent',
  name: 'support-agent',
  instructions: 'You help customers with billing and account questions.',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new ClassifierProcessor({
      classifier: topic,
      lastMessageOnly: true,
      decide: decisions.blockUnless('topic', {
        oneOf: ['billing', 'account'],
        reason: 'This assistant only handles billing and account questions',
      }),
    }),
  ],
})
```

### Output quality gate with `filter`

```typescript title="src/mastra/agents/quality-gated-agent.ts"
import { Agent } from '@mastra/core/agent'
import { Classifier } from '@mastra/core/classifier'
import { ClassifierProcessor, decisions } from '@mastra/core/processors'

const quality = new Classifier({
  id: 'quality',
  model,
  questions: {
    quality: {
      type: 'score',
      instructions: 'Rate how well the response answers the user',
      criteria: ['Off-topic', 'Partial', 'Complete'],
    },
  },
})

export const agent = new Agent({
  id: 'quality-gated-agent',
  name: 'quality-gated-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  outputProcessors: [
    new ClassifierProcessor({
      classifier: quality,
      decide: decisions.blockIf('quality', {
        scoreBelow: 1,
        action: 'filter',
        reason: 'Low quality response',
      }),
    }),
  ],
})
```

### Custom `decide` with phase awareness

```typescript
import { ClassifierProcessor } from '@mastra/core/processors'

const processor = new ClassifierProcessor({
  classifier: safety,
  decide: (answers, ctx) => {
    if (answers.unsafe.probability < 0.5) return { action: 'pass' }
    // Drop unsafe output chunks silently, but reject unsafe input outright
    if (ctx.phase === 'stream') return { action: 'filter' }
    return { action: 'block', reason: 'Message rejected by safety policy' }
  },
})
```

### Registered classifier

Register the classifier on the `Mastra` instance and reference it by key or ID. The processor resolves it on first use.

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Classifier } from '@mastra/core/classifier'

export const mastra = new Mastra({
  classifiers: {
    safety: new Classifier({ id: 'safety', model, questions: {/* ... */} }),
  },
})
```

```typescript
import { ClassifierProcessor, decisions } from '@mastra/core/processors'

const processor = new ClassifierProcessor({
  classifier: 'safety',
  decide: decisions.blockIf('unsafe', { probability: 0.8, reason: 'Rejected' }),
})
```

When using a registered classifier by string, answer types are not inferred; provide `questions` to the processor to narrow them, or index `answers` generically.
