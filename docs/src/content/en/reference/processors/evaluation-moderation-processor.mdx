# EvaluationModerationProcessor

The `EvaluationModerationProcessor` is an **input processor** that guards agent input with an evaluation model — a classifier that answers typed questions (a probability, a one-of-N choice) and emits no text. Use it when moderation should be decided by a dedicated evaluation model such as TypeSafe Jev rather than by a language model whose verdict is parsed out of generated text, which is what [`ModerationProcessor`](/reference/processors/moderation-processor) does.

The processor evaluates the text of the last message only, truncated to `maxChars`, and aborts the turn with a fixed reason code when the returned score reaches `threshold`. It fails open on evaluation failure — timeout, transport error, or an open circuit breaker lets the message through with one log line. The message text is never logged.

## Usage example

```typescript
import { EvaluationModerationProcessor, createJevEvaluator } from '@mastra/core/processors'

const processor = new EvaluationModerationProcessor({
  evaluate: createJevEvaluator({
    apiKey: process.env.TYPESAFE_API_KEY!,
    // Optional: one sentence about your assistant sharpens the verdicts.
    context: 'A general-purpose customer support assistant.',
  }),
  threshold: 0.7,
})
```

## `createJevEvaluator(options)`

Builds an `evaluate` function backed by TypeSafe Jev's System One API. One request per call asks two questions: `blocking` (a yes/no probability — the gate) and `category` (a choice label used only for logging, optional in parsing so a missing label never turns a block into a pass). Throws on HTTP errors and unparsable answers; the processor's `errorStrategy` decides what a failure means.

## `isModerationBlock(tripwire, reason?)`

Tells a moderation block from an ordinary stop: a user-stopped run carries a tripwire too, with a different reason, so "any tripwire" is not a block. Pass the same `reason` you configured on the processor.

```typescript
import { isModerationBlock } from '@mastra/core/processors'

if (isModerationBlock(result.tripwire)) {
  // the input was blocked by the processor
}
```

## Extended usage example

```typescript title="src/mastra/agents/moderated-agent.ts"
import { Agent } from '@mastra/core/agent'
import { EvaluationModerationProcessor, createJevEvaluator } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'moderated-agent',
  name: 'moderated-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  inputProcessors: [
    new EvaluationModerationProcessor({
      evaluate: createJevEvaluator({ apiKey: process.env.TYPESAFE_API_KEY! }),
      threshold: 0.7,
      onVerdict: verdict => {
        // verdict.tokensIn / verdict.model for cost accounting
      },
    }),
  ],
})
```
