# SystemPromptScrubber

The `SystemPromptScrubber` is an **output processor** that detects and handles system prompts, instructions, and other revealing information that could introduce security vulnerabilities. This processor helps maintain security by identifying types of system prompts and providing flexible strategies for handling them, including multiple redaction methods to ensure sensitive information is properly sanitized.

## Usage example

```typescript
import { SystemPromptScrubber } from '@mastra/core/processors'

const processor = new SystemPromptScrubber({
  model: 'openrouter/openai/gpt-oss-safeguard-20b',
  strategy: 'redact',
  redactionMethod: 'mask',
  includeDetections: true,
  lastMessageOnly: true,
})
```

## Extended usage example

`SystemPromptScrubber` buffers streamed text by default, so it makes one detection call per sentence instead of one per chunk. The buffer flushes at a sentence boundary, when it reaches `bufferSize` characters, or before a non-text part. Use `bufferSize` to control how much text each detection call sees.

`BatchPartsProcessor` is optional. Add it before `SystemPromptScrubber` when you also want to coalesce stream parts.

```typescript title="src/mastra/agents/scrubbed-agent.ts"
import { Agent } from '@mastra/core/agent'
import { BatchPartsProcessor, SystemPromptScrubber } from '@mastra/core/processors'

export const agent = new Agent({
  id: 'scrubbed-agent',
  name: 'scrubbed-agent',
  instructions: 'You are a helpful assistant',
  model: '__GATEWAY_OPENAI_MODEL__',
  outputProcessors: [
    // Optional: coalesce stream parts before detection
    new BatchPartsProcessor({
      batchSize: 10,
    }),
    // Detect system prompts in the buffered text
    new SystemPromptScrubber({
      model: 'openrouter/openai/gpt-oss-safeguard-20b',
      strategy: 'redact',
      customPatterns: ['system prompt', 'internal instructions'],
      includeDetections: true,
      redactionMethod: 'placeholder',
      placeholderText: '[REDACTED]',
    }),
  ],
})
```
