# ToolResultTokenLimiter

The `ToolResultTokenLimiter` is an **output processor** that caps how many tokens of each tool result the model reads. It runs once per result through the [`processToolModelOutput`](/reference/processors/processor-interface) hook, after the tool returns. The stored and streamed result stays whole. Only the copy the model reads on later steps is truncated. See [Behavior](#behavior).

## Usage example

```typescript
import { Agent } from '@mastra/core/agent'
import { TokenLimiterProcessor, ToolResultTokenLimiter } from '@mastra/core/processors'

const agent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  instructions: 'You research topics using the available tools.',
  model: '__GATEWAY_OPENAI_MODEL__',
  tools: { fetchPage },
  inputProcessors: [new TokenLimiterProcessor({ limit: 8000 })],
  outputProcessors: [new ToolResultTokenLimiter({ limit: 4000 })],
})
```

When you use it with [`TokenLimiterProcessor`](/reference/processors/token-limiter-processor), set the per-result limit well below that budget. The prompt budget also counts the tool call arguments, message roles, system messages, and per-message overhead, so a result capped at the full budget still doesn't fit.

## Behavior

- Results at or under the limit pass through unchanged.
- Larger results are cut to fit the limit and end with a marker such as `[truncated: showing 2,000 of 18,400 tokens]`, so the model can see the result is partial and ask for less. Token counts are estimates.
- Only the model-facing copy is truncated. Memory, message history, streamed chunks, and the UI keep the full result with its original type. The capped copy is stored with the message and reused on later steps, so each result is truncated once.
- For tools that define `toModelOutput`, the mapped output is capped. Text and JSON outputs are capped, and so are text entries of `content` outputs. Media entries are left unchanged.
- Without `toModelOutput`, the model reads a capped text copy of the result. Objects are converted to JSON text for that copy only.
- Media results such as `{ data, mediaType }` pass through unchanged.
- Background task results are limited too, including ones that arrive after the turn ends. On a durable agent, a result that arrives after a process restart passes through unchanged if the run is no longer registered.
- Tool errors, results from provider-executed tools, and results that can't be serialized to JSON pass through unchanged.
- Each tool result is limited on its own. Use [`TokenLimiterProcessor`](/reference/processors/token-limiter-processor) to limit the total size of the prompt. It counts the capped copy, not the full result.
