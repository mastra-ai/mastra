# createLinearTools()

Returns a curated Linear toolset that executes through the Mastra platform connection proxy. Tools never handle provider credentials directly.

```typescript
import { createLinearTools } from '@mastra/connect'

const tools = createLinearTools()
```

The returned object is a `ToolsInput`: spread it into an agent's `tools`, or pass it through `toolsets`.

## Tools

| Tool | Description |
| - | - |
