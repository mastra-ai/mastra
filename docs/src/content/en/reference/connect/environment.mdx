# environment()

Resolves a project's platform connections into sandbox credentials: environment variables plus a start hook that finishes in-sandbox setup. Use it when agents run inside a sandbox that shells out to CLIs (`git`, `gh`) or needs provider tokens in the process environment, so a project that already has GitHub attached needs no separate credential wiring.

```typescript
import { environment } from '@mastra/connect'

const { env, onStart } = await environment()

const sandbox = new E2BSandbox({ env, onStart })
// in the sandbox: `gh pr list` and `git clone https://github.com/org/repo` just work
```

Returns: `Promise<ConnectEnvironment>`:

```typescript
interface ConnectEnvironment {
  /** Environment variables to inject into the sandbox (e.g. GH_TOKEN). Never log these. */
  env: Record<string, string | undefined>
  /** Runs provider setup inside the sandbox (e.g. git credential wiring). Safe no-op when nothing to do. */
  onStart: SandboxStartHook
}
```

GitHub is the first provider with an environment contributor. Its OAuth token is exported as `GH_TOKEN` and `GITHUB_TOKEN`, so both `gh` and `git` HTTPS operations authenticate as the connected user, and `onStart` wires a git credential helper that reads the token from the environment rather than baking it into git config. More providers plug in over time.

## Behavior

Connection resolution matches [`tools()`](/reference/connect/tools): a per-provider `connectionId` or the provider's `MASTRA_<PROVIDER>_CONNECTION_ID` env var wins, else a single active connection is used. Ambiguity, `needs_reauth` status, and credential-fetch failures warn and skip that provider. Configuration errors (missing project ID, malformed provider ID) throw at call time so they surface at startup.

The returned `env` is a snapshot, not a live resolver. OAuth tokens expire, so call `environment()` again for a fresh token when starting new sandboxes. Never log the returned values.

## Errors

Throws `MastraConnectError` with a `code` property:

| Code | When |
| - | - |
| `missing_project_id` | No project ID configured |
| `missing_access_token` | No platform token configured |
| `invalid_options` | Malformed provider ID in `integrations` |
| `unauthorized` | The platform rejected the token (401/403) |
| `platform_error` | Any other platform request failure |
