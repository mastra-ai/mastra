# createNeonTools()

Returns a curated Neon toolset over the Neon console API that executes through the Mastra platform connection proxy. Tools never handle provider credentials directly.

```typescript
import { createNeonTools } from '@mastra/connect'

const tools = createNeonTools()
```

The returned object is a `ToolsInput`: spread it into an agent's `tools`, or pass it through `toolsets`.

`neon_list_endpoints` returns connection metadata (hosts and roles) only, never passwords. To build a connection string yourself, use [`credential()`](/reference/connect/credential) and handle the result carefully.
