# createResendTools()

Returns a curated Resend toolset that executes through the Mastra platform connection proxy. Tools never handle provider credentials directly.

```typescript
import { createResendTools } from '@mastra/connect'

const tools = createResendTools()
```

The returned object is a `ToolsInput`: spread it into an agent's `tools`, or pass it through `toolsets`.

## Tools

| Tool | Description |
| - | - |
| `resend_send_email` | Send an email. Requires plain text and/or HTML content |
| `resend_get_email` | Get a previously sent email by id, including its content and last delivery event |
| `resend_list_domains` | List the sending domains configured in Resend |
| `resend_list_audiences` | List contact audiences (mailing lists) |
| `resend_create_contact` | Add a contact to an audience |
| `resend_list_contacts` | List the contacts of an audience |
| `resend_list_broadcasts` | List email broadcasts (bulk sends) |
