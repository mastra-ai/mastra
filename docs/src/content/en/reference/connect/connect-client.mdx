# ConnectClient

`ConnectClient` is a typed client for the Mastra platform integrations API. Use it when your code manages connections itself: it lists a project's connections, reads credentials and connection context, calls providers through the platform proxy, and starts connect sessions. Its [`events`](/reference/connect/events) property reads provider events as they arrive.

To give an agent tools, use [`tools()`](/reference/connect/tools) instead.

## Usage example

```typescript title="src/sync.ts"
import { ConnectClient } from '@mastra/connect'

const connect = new ConnectClient()

const [jira] = await connect.listConnections({ providerKeys: ['jira'] })
if (jira) {
  const issue = await connect.proxy(jira.id, {
    method: 'GET',
    path: '/rest/api/3/issue/ENG-1',
  })
}
```

The client reads `MASTRA_PLATFORM_ACCESS_TOKEN` and `MASTRA_PROJECT_ID` from the environment, the same as `tools()`.

## Methods

### `listConnections(input?)`

Returns the connections linked to the project as `Promise<ProjectConnection[]>`. Each connection has `id`, `integrationId`, `status`, and optional `accountLabel`, `connectedAt`, `createdAt`, `connectedByUserId`, and `resourceId`. A `resourceId` of `null` marks a connection shared by all users of the project.

Only connections linked to the project are returned. Connections that belong to the organization but aren't linked to the project are left out. Use `linkConnection()` to add them.

### `linkConnection(connectionId, input?)`

Links an organization connection to the project, so `listConnections()` returns it and its events reach the project's topics. Linking an already linked connection succeeds. Pass `input.projectId` to link to another project. Returns `Promise<void>`.

### `listIntegrations()`

Returns the integration catalog as `Promise<IntegrationCatalogEntry[]>`. Each entry has an `id`, such as `linear`, and `capabilities.mcp`, which is `true` for providers served over MCP. Entries can also include `displayName`, `logoUrl`, `authType`, and `authFields`.

### `getCredential(connectionId)`

Returns the connection's raw credential as `Promise<ConnectionCredential>`, the same type as [`credential()`](/reference/connect/credential).

### `getContext(connectionId)`

Returns `Promise<{ connection_config, metadata }>` for the connection. Both are provider-specific records or `null`. For example, a GitHub App connection stores its installation ID in `connection_config`.

### `proxy(connectionId, request)`

Calls the provider through the platform proxy and returns its parsed body as `Promise<unknown>`. A body that isn't valid JSON is returned as text. The platform adds credentials, so they never reach your code.

### `proxyWithResponse(connectionId, request)`

Same as `proxy()`, but returns `Promise<{ data, status, headers }>` so you can read the provider's status and headers. `data` is the parsed body.

### `createConnectSession(integrationId, input?)`

Starts a session to connect a new account. The resulting connection is linked to the project. Pass `input.projectId` to use another project. On a client created with `withResource()`, the connection belongs to that end user.

Returns `Promise<ConnectSession>` with `connectionId`, `integrationId`, `connectUrl`, `sessionToken`, and `expiresAt`. Send the user to `connectUrl` to finish connecting. For sessions scoped to an end user, `connectUrl` and `sessionToken` are `null`. Call `getConnectUrl()` to get the link.

### `createReconnectSession(connectionId)`

Starts a session to re-authorize an existing connection whose status is `active` or `needs_reauth`. Returns `Promise<ConnectSession>`.

### `getConnectUrl(connectionId)`

Returns `Promise<{ connectUrl, expiresAt }>` for a connection scoped to an end user. Call it on a client created with `withResource()`, with the same resource key that started the session. The link is available only while the session is pending and unexpired. Otherwise, the call throws `connection_not_found`.

### `disconnect(connectionId)`

Disconnects the connection. The platform removes it from the provider in the background. Returns `Promise<void>`.

### `withResource(resourceId)`

Returns a new `ConnectClient` that sends `resourceId` as the end-user resource key. The original client is unchanged. Use it for connections scoped to one of your users.

### `request(method, path, init?)`

Calls a platform route that the typed methods don't cover, and returns `Promise<T>` with the parsed JSON body, or `undefined` for an empty body. `method` is one of `GET`, `HEAD`, `POST`, `PUT`, `PATCH`, or `DELETE`. `path` must start with a single `/` and can't contain `.` or `..` segments. A response outside the 2xx range throws `MastraConnectError`.

### `fetchRaw(method, path, init?)`

Same as `request()`, but doesn't follow redirects and returns `Promise<Response>` without checking its status. Use it for routes that answer with a redirect.

Every method throws `MastraConnectError`, exported from `@mastra/connect`. It has these fields:

Check `problemCode` rather than `code` to detect a platform condition. A proxied call that fails because the connection needs re-authorization throws `proxy_error` with `problemCode` set to `connection_needs_reauth`:

```typescript
import { MastraConnectError } from '@mastra/connect'

try {
  await connect.proxy(connectionId, { method: 'GET', path: '/me' })
} catch (error) {
  if (
    error instanceof MastraConnectError &&
    error.source === 'platform' &&
    error.problemCode === 'connection_needs_reauth'
  ) {
    const session = await connect.createReconnectSession(connectionId)
    // Send the user to session.connectUrl
  }
}
```

`code` is one of these values. The last group comes from other `@mastra/connect` APIs that throw the same error class.

| Code | When |
| - | - |
| `missing_access_token` | No platform token is configured |
| `missing_project_id` | A project call has no project from the call, the client, or `MASTRA_PROJECT_ID` |
| `invalid_options` | An argument is invalid, such as a path with `..` segments, an empty `resourceId`, or a non-positive `timeoutMs` |
| `timeout` | A call took longer than `timeoutMs` |
| `unauthorized` | The platform rejected the token (401 or 403) |
| `connection_not_found` | The connection doesn't exist or isn't accessible, or `getConnectUrl()` found no pending session |
| `proxy_error` | A proxied call failed. Check `source` to see whether the platform or the provider answered |
| `unsupported_credential_type` | `getCredential()` received a credential type this package doesn't support |
| `platform_error` | Any other platform failure, including a response with an unexpected shape |
| `invalid_cursor` | The events service rejected a resume cursor. See [Events client](/reference/connect/events) |
| `invalid_response` | The events service sent a frame that doesn't match its contract |
| `missing_connection_id` | A provider toolset was created without a connection ID |
| `no_active_connection` | [`channels()`](/reference/connect/channels) found no active connection for a channel provider |
| `unknown_connection` | A tool call named a `connection_name` that matches no active connection |
