# DatasetsManager.delete()

**Added in:** `@mastra/core@1.4.0`

Deletes a dataset by ID, including all of its items and versions. Experiments that ran against the dataset are kept but detached: their `datasetId` and `datasetVersion` are set to `null`. Database-backed storage adapters also remove the results of those experiments.

## Usage example

```typescript
import { Mastra } from '@mastra/core'

const mastra = new Mastra({/* storage config */})

await mastra.datasets.delete({ id: 'dataset-id' })
```

When `organizationId` or `projectId` is provided, deletion is scoped to those values. A tenancy mismatch is a silent no-op.
