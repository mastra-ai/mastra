# Mastra.getWorkspaceById()

The `.getWorkspaceById()` method returns a workspace registered with the Mastra instance. By default, it throws when no workspace exists for the ID. Pass `{ optional: true }` to get `undefined` instead, for example to check whether a workspace exists before creating it.

## Usage example

```typescript
const workspace = mastra.getWorkspaceById('workspace-123')
```

Check for a workspace without throwing:

```typescript
const existing = mastra.getWorkspaceById('workspace-456', { optional: true })
if (!existing) {
  // Create and register the workspace
}
```
