# getClassifierById()

The `getClassifierById()` method retrieves a classifier by searching for its `id` property, then falls back to the registration key. `ClassifierProcessor` uses this method to resolve a classifier referenced by string.

## Usage example

```typescript
import { mastra } from './mastra'

const safety = mastra.getClassifierById('safety')
```

## Error handling

This method throws a `MastraError` with id `MASTRA_GET_CLASSIFIER_BY_ID_NOT_FOUND` if no classifier matches the specified id or key.
