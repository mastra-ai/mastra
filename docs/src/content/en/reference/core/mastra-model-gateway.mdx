# MastraModelGateway

Abstract base class for implementing custom model gateways. Gateways handle provider-specific logic for accessing language models, including provider configuration, authentication, URL construction, and model instantiation.

Use `MastraModelGatewayInterface` when you want to provide a plain object gateway instead of extending the base class.

## Class overview

```typescript
import { MastraModelGateway, type ProviderConfig } from '@mastra/core/llm'
import { createOpenAICompatible } from '@ai-sdk/openai-compatible-v5'
import type { LanguageModelV2 } from '@ai-sdk/provider-v5'

class MyCustomGateway extends MastraModelGateway {
  readonly id = 'custom'
  readonly name = 'My Custom Gateway'

  async fetchProviders(): Promise<Record<string, ProviderConfig>> {
    return {
      'my-provider': {
        name: 'My Provider',
        models: ['__GATEWAY_OPENAI_MODEL__', '__GATEWAY_ANTHROPIC_MODEL_SONNET__'],
        apiKeyEnvVar: 'MY_API_KEY',
        gateway: this.id,
      },
    }
  }

  buildUrl(modelId: string, envVars?: Record<string, string>): string {
    return 'https://api.my-provider.com/v1'
  }

  async getApiKey(modelId: string): Promise<string> {
    const apiKey = process.env.MY_API_KEY
    if (!apiKey) throw new Error('MY_API_KEY not set')
    return apiKey
  }

  async resolveLanguageModel({
    modelId,
    providerId,
    apiKey,
  }: {
    modelId: string
    providerId: string
    apiKey: string
  }): Promise<LanguageModelV2> {
    const baseURL = this.buildUrl(`${providerId}/${modelId}`)
    return createOpenAICompatible({
      name: providerId,
      apiKey,
      baseURL,
    }).chatModel(modelId)
  }
}
```

### `resolveAuth()`

Resolves credentials before Mastra creates the language model. Implement this optional hook when a gateway owns authentication. If omitted, Mastra falls back to `getApiKey()`.

**Parameters:**

<PropertiesTable
  content={[
  {
    name: 'request',
    type: 'GatewayAuthRequest',
    description:
      'Incoming request context containing gatewayId, providerId, modelId, and routerId for the gateway to inspect and validate.',
  },
]}
/>

**Returns:** `GatewayAuthResult | undefined | Promise<GatewayAuthResult | undefined>`

A `GatewayAuthResult` may include `apiKey`, `bearerToken`, `headers`, and an optional `source` field to trace where auth came from.

Studio uses this hook to check which models have credentials. A provider response includes `connectedModels`, an array of authenticated model IDs without the provider prefix. `connected` is `true` when that array has at least one model. Studio checks the selected model against this list, and the agent builder offers only those models. Older servers that omit `connectedModels` retain provider-level connection checks in Studio.

The server checks models sequentially within each provider, with a five-second deadline per provider. On timeout, it returns the models checked successfully so far and stops starting further checks. The deadline doesn't cancel an auth request already in progress. Unexpected auth errors are logged once per provider without preventing other providers from loading. Gateway provider discovery runs before this deadline.

#### Check model authentication

Use `GatewayManager.hasAuth(routerId)` to check a model through the registered gateway chain:

```typescript
import { GatewayManager } from '@mastra/core/llm'
import { mastra } from './mastra'

const gateways = new GatewayManager(Object.values(mastra.listGateways() ?? {}))
const hasAuth = await gateways.hasAuth('__GATEWAY_OPENAI_MODEL__')
```

**Returns:** `Promise<boolean>`. Missing credentials return `false`; unexpected gateway errors reject the promise. This checks whether credentials are available, without validating them against the provider or generating a response. Auth resolution may perform network requests, such as a token exchange.

`GatewayManager.listAvailableModels()` returns a `hasApiKey` flag for each model using the same check. Despite the field name, OAuth and header-based credentials count too.

For an existing `ModelRouterLanguageModel`, call `model.hasAuth()` to use that instance's gateway chain and explicit `apiKey` or `url` configuration. Direct AI SDK model instances don't inherit credentials from registered gateways.

## Model ID format

For true gateways, the gateway ID is used as a prefix and models are accessed using this format:

```
[gateway-id]/[provider]/[model]
```

Examples:

- Gateway with `id = 'custom'`: `'custom/my-provider/model-1'`
