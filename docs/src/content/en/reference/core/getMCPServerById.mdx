# Mastra.getMCPServerById()

The `.getMCPServerById()` method retrieves an MCP server instance by its intrinsic `id` property. For retrieving by registry key (the key used in configuration), use `.getMCPServer()` instead.

## Usage example

```typescript
// Register an MCP server with a registry key
const myServer = new MCPServer({
  id: 'my-mcp-server',
  name: 'My Server',
  version: '1.0.0',
  tools: {/* ... */},
})

export const mastra = new Mastra({
  mcpServers: {
    customKey: myServer, // 'customKey' is the registry key
  },
})

// Retrieve by intrinsic ID
const server = mastra.getMCPServerById('my-mcp-server')

// Alternatively, retrieve by registry key
const serverByKey = mastra.getMCPServer('customKey')
```

## Notes

- MCP 1.x server IDs are slugified during construction. The core `MCPServerBaseV2` preserves an explicitly supplied ID.
- The result can be either server family. See [MCP v1 and v2 server contracts](/reference/core/getMCPServer#mcp-v1-and-v2-servers) for narrowing and execution.
- Use `version` to select an exact version when multiple servers share an intrinsic ID.
- Without `version`, the method selects the most recent valid `releaseDate`. If multiple matches have no valid release date, it returns `undefined`.
