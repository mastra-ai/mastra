# Knowledge class

:::warning

Knowledge is experimental and can change without notice.

:::

```typescript
import { Knowledge } from '@mastra/core/knowledge'
```

## Methods

- `createTools({ read, write, pins })`: returns the Knowledge tools for explicit wiring.
- `getInstructions({ read, write, pins })`: returns the instruction block for those tools.
