# WorkspaceSandbox

**Added in:** `@mastra/core@1.1.0`

The `WorkspaceSandbox` interface defines how workspaces execute commands. Optional provider capabilities cover process and file management. Providers may also support public port URLs, mounts, or cloning.

## Methods

### `start()`

Starts the sandbox and is called automatically by `workspace.init()` or the first `executeCommand()` call.

```typescript
await sandbox.start()
```

This method prepares the sandbox for command execution.

### `stop()`

Stop the sandbox. Persistence and reconnection behavior are provider-specific.

```typescript
await sandbox.stop?.()
```

Don't assume that files or processes survive this operation. Check the selected provider's reference before using `stop()` as a pause or persistence boundary.

### `destroy()`

Clean up sandbox resources. Called by `workspace.destroy()`.

```typescript
await sandbox.destroy()
```

### `clone(options?)`

Create an independent sandbox that inherits the provider configuration. The clone doesn't start or perform network operations until its own `start()` or command call.

```typescript
const projectSandbox = sandbox.clone?.({
  id: 'project-123',
  env: { NODE_ENV: 'development' },
  workingDirectory: '/workspace',
})
```

### `writeFiles(files)`

Write multiple files through a provider's native upload API. This is optional and writes to the sandbox's own filesystem, not the configured `WorkspaceFilesystem`.

```typescript
await sandbox.writeFiles?.([
  { path: '/workspace/package.json', content: '{"type":"module"}' },
  { path: '/workspace/index.mjs', content: sourceCode },
])
```

**Returns:** `Promise<void>`

### `mount(filesystem, mountPath)`

Mount a compatible workspace filesystem into the sandbox. This method is available only when the provider supports mounts.

```typescript
const result = await sandbox.mount?.(filesystem, '/data')
```

**Returns:** `Promise<MountResult> | undefined`

### `unmount(mountPath)`

Unmount a workspace filesystem from the sandbox.

```typescript
await sandbox.unmount?.('/data')
```

**Returns:** `Promise<void> | undefined`

### `isReady()`

Check whether the sandbox is ready for operations.

```typescript
const ready = await sandbox.isReady?.()
```

**Returns:** `Promise<boolean> | undefined`

### `getInfo()`

Get sandbox status and resource information.

```typescript
const info = await sandbox.getInfo()
// { status: 'running', resources: { memoryMB: 512, cpuPercent: 5 } }
```

### `networking.getPortUrl(port)`

Get the public URL for an exposed port. This capability is optional and doesn't change the sandbox's network policy.

```typescript
const url = await sandbox.networking?.getPortUrl(8000)
```

**Returns:** `Promise<string | null> | undefined`

### `getInstructions(opts?)`

Returns a description of how this sandbox works. Injected into the agent's system message when the workspace is assigned to an agent.

```typescript
const instructions = sandbox.getInstructions?.()
// 'Local command execution. Working directory: "/workspace".'
```
