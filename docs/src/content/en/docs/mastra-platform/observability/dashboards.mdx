# Build custom dashboards

A custom dashboard is a saved set of charts and numbers on the Mastra platform **Metrics** page. Use dashboards to keep the views your team checks often, such as failed runs per agent, cost per model, or tool latency, next to the built-in **Metrics** dashboard.

By the end of this page, you'll have a saved dashboard with at least one widget that your organization can open from the **Metrics** page.

Custom dashboards are a Mastra platform feature. They're separate from local Studio, and from the [observability query APIs](/docs/mastra-platform/observability/overview#query-observability-data) you can use to build your own visualizations.

## Before you begin

- Send traces to Mastra Platform Observability. Follow [Observability on Mastra platform](/docs/mastra-platform/observability/overview) if your project doesn't send data yet. Widgets chart only the data your application has sent.
- Use an organization member or admin account. Viewers can open dashboards but can't create, change, or save them.

## Create a dashboard

<Steps>
  <StepItem>
    Open the [Mastra platform dashboard](https://projects.mastra.ai) without selecting a project, then select **Observability** > **Metrics**. The **Dashboards** page lists the organization's dashboards, starting with **Metrics**.

    If **Metrics** opens a single dashboard instead of the **Dashboards** list, custom dashboards aren't available for your organization yet.
  </StepItem>

  <StepItem>
    Select **Add dashboard**, enter a **Dashboard name**, then select **Create dashboard**. Mastra creates an empty dashboard and opens it.
  </StepItem>

  <StepItem>
    Select **Add widget**, next to the filters. The dashboard shows a new **Untitled widget** card.
  </StepItem>

  <StepItem>
    On the new card, select **Configure**. In the dialog, enter a title, choose the widget type, and pick the metrics the widget shows. The preview updates as you change the settings. Select **Save** to apply them to the card.
  </StepItem>

  <StepItem>
    Select **Save** next to the filters to keep the dashboard.
  </StepItem>

  <StepItem>
    Check the result. Select **Metrics** in the breadcrumb. Your dashboard is in the **Dashboards** list with its widget count, and other members of your organization see it too.
  </StepItem>
</Steps>

## Manage dashboards

After you create a dashboard, add and arrange its widgets, filter them, and manage the dashboard itself.

### Add and configure widgets

Select **Add widget** to add an empty card to the dashboard, then select **Configure** on the card. A dashboard holds up to 20 widgets.

In the **Configure** dialog, you can:

- Change the widget title at the top of the dialog.
- Choose the widget type: **KPI**, **Line**, **Stacked bars**, **Table**, or **Scores**. A type that can't show the selected metrics is unavailable.
- Select **Add tab** to give the widget more than one view, each with its own metrics.

Select **Save** in the dialog to apply the changes to the card.

### Arrange widgets

Members and admins can change a dashboard in place:

- Drag a widget to move it between rows, or resize it.
- Select **Configure \<widget name>** on a widget to change it.
- Select **Unpin \<widget name>** on a widget to remove it from the dashboard. A new widget that you haven't configured shows **Remove \<widget name>** instead.

Changes stay in a draft until you select **Save** next to the filters. Select **Cancel** to discard them. Mastra asks before you leave a dashboard with changes that aren't saved.

### Filter dashboards

Widgets use the date range, project, and filters selected above the dashboard. Change them to see the same dashboard for another period or subset of your data. When you select a project, the dashboard shows that project's data and becomes read-only.

### Rename or delete a dashboard

On the **Dashboards** list or on the dashboard's page, select **More actions for \<dashboard name>**, then select **Rename** or **Delete**. Deleting a dashboard removes it and its widgets for everyone in the organization.

### Change the Metrics dashboard

The **Metrics** dashboard is the default dashboard in the list. Members and admins can arrange and save it like a custom dashboard, and the saved version replaces the default for the organization. The **Metrics** dashboard can't be renamed or deleted.

A project's **Metrics** page shows a single, read-only **Metrics** dashboard for that project.

### Create alerts from widgets

Organization admins can create an alert from a dashboard widget on the organization or a project **Metrics** page. Select **Create alert** on the widget, then review and save the alert. See [Create an alert from a dashboard card](/docs/mastra-platform/observability/alerts#create-an-alert-from-a-dashboard-card) for the widgets that support alerts.
