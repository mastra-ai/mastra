# Build custom dashboards

A custom dashboard is a saved set of charts and numbers on the Mastra platform **Metrics** page. Use dashboards to keep the views your team checks often, such as failed runs per agent, cost per model, or tool latency, next to the built-in **Default** dashboard.

By the end of this page, you'll have a saved dashboard with at least one widget that your organization can open from the **Metrics** page.

Custom dashboards are a Mastra platform feature. They're separate from local Studio, and from the [observability query APIs](/docs/mastra-platform/observability/overview#query-observability-data) you can use to build your own visualizations.

## Before you begin

- Send traces to Mastra Platform Observability. Follow [Observability on Mastra platform](/docs/mastra-platform/observability/overview) if your project doesn't send data yet. Widgets chart only the data your application has sent.
- Use an organization member or admin account. Viewers can open dashboards but can't create, change, or save them.

## Create a dashboard

<Steps>
  <StepItem>
    Open the [Mastra platform dashboard](https://projects.mastra.ai) without selecting a project, then select **Observability** > **Metrics**. The **Dashboards** page lists the organization's dashboards, starting with **Default**.

    If **Metrics** opens a single dashboard instead of the **Dashboards** list, custom dashboards aren't available for your organization yet.
  </StepItem>

  <StepItem>
    Select **Add dashboard**, enter a **Dashboard name**, then select **Create dashboard**. Mastra creates an empty dashboard and opens it.
  </StepItem>

  <StepItem>
    Select **Add widget** at the top of the page. In the **Add widgets** dialog, pick one or more ready-made widgets, such as agent runs, latency, or cost per model, then select **Add \<number> widgets**. To build your own chart instead, select **Create custom widget…**.
  </StepItem>

  <StepItem>
    Check the result. The widgets appear at the top of the dashboard, and Mastra saves the change as you make it. Select **Metrics** in the breadcrumb. Your dashboard is in the **Dashboards** list with its widget count, and other members of your organization see it too.
  </StepItem>
</Steps>

## Manage dashboards

After you create a dashboard, add and arrange its widgets, filter them, and manage the dashboard itself. Mastra saves each change as soon as you make it and shows **Saving…** in the header while it does. If a change can't be saved, the dashboard goes back to how it was and Mastra shows the reason.

### Add widgets

Select **Add widget** at the top of the dashboard. The **Add widgets** dialog lists ready-made widgets under **Overview**, **Activity**, and **Performance and cost**, and previews the highlighted one. Widgets the dashboard already has are tagged **On dashboard**. Search the list, pick as many widgets as you need, then select **Add \<number> widgets**. To remove the widgets you added, select **Undo** in the confirmation message.

A dashboard holds up to 20 widgets. When it's full, **Add widget** is unavailable until you unpin a widget.

### Build a custom widget

To chart something the ready-made widgets don't cover, select **Create custom widget…** at the end of the **Add widgets** list. To place the widget at a specific spot, select **Add widget here** or **Add widget on a new row** between widgets instead.

In the widget editor, you can:

- Change the widget title at the top.
- Choose the widget type: **KPI**, **Line**, **Stacked bars**, **Table**, or **Scores**. A type that can't show the selected metrics is unavailable.
- Pick the metrics the widget shows. The preview updates as you change the settings.
- Select **Add tab** to give the widget more than one view, each with its own metrics.

Select **Save** to add the widget. The widget isn't added until you save it.

### Arrange and change widgets

Members and admins can change a dashboard in place:

- Drag **Move widget** to move a widget. Each row holds one full-width widget or two side by side.
- Select **Configure \<widget name>** on a widget to open the widget editor, then select **Save** to apply the changes.
- Select **Unpin \<widget name>** to remove a widget from the dashboard.

### Filter dashboards

Widgets use the date range, project, and filters selected above the dashboard. Change them to see the same dashboard for another period or subset of your data. When you select a project, the dashboard shows that project's data and becomes read-only.

### Rename or delete a dashboard

On the **Dashboards** list or on the dashboard's page, select **More actions for \<dashboard name>**, then select **Rename** or **Delete**. Deleting a dashboard removes it and its widgets for everyone in the organization.

### Change the default dashboard

The **Default** dashboard comes first in the list and starts with the built-in metrics charts. Members and admins can change it like a custom dashboard, and the changed version replaces the built-in one for the organization. The **Default** dashboard can't be renamed or deleted, and no other dashboard can be named **Default**.

A project's **Metrics** page shows a single, read-only dashboard for that project.

### Create alerts from widgets

Organization admins can create an alert from a dashboard widget on the organization or a project **Metrics** page. Select **Create alert** on the widget, then review and save the alert. See [Create an alert from a dashboard card](/docs/mastra-platform/observability/alerts#create-an-alert-from-a-dashboard-card) for the widgets that support alerts.
