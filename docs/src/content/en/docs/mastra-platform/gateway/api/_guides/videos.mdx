Video generation runs as a job. Create a job, [poll it](/docs/mastra-platform/gateway/api/videos/retrieve) until it finishes, then [download the video](/docs/mastra-platform/gateway/api/videos/content). Replace `google/veo-3.1` with any video model from [`/v1/models`](/docs/mastra-platform/gateway/api/models).

```bash
curl https://gateway-api.mastra.ai/v1/videos \
  -H "Authorization: Bearer $MASTRA_GATEWAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google/veo-3.1",
    "prompt": "A lighthouse at dusk, waves crashing, slow aerial pan",
    "duration": 8,
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'
```

Each job produces one video. Unknown fields return `422`. Each model supports its own set of durations, resolutions, and aspect ratios. If no route serves the combination you ask for, the request is refused before any credit is held.

The response returns `202` with the job:

```json
{
  "id": "...",
  "object": "video",
  "model": "google/veo-3.1",
  "status": "pending",
  "created_at": 1763460000
}
```

## Billing

Gateway holds credit for the requested duration when the job is created, then settles on the provider's reported cost. A job that produces no video isn't charged.
