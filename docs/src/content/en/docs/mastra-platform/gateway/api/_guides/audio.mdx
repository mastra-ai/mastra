Compatible with the OpenAI Audio API. List speech models with [`/v1/models`](/docs/mastra-platform/gateway/api/models). Each speech model's `endpoints` includes `speech`. To turn audio into text, see [Create a transcription](/docs/mastra-platform/gateway/api/audio/transcriptions).

```bash
curl https://gateway-api.mastra.ai/v1/audio/speech \
  -H "Authorization: Bearer $MASTRA_GATEWAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "elevenlabs/eleven-flash-v2.5",
    "input": "Hello from Gateway.",
    "voice": "YOUR_VOICE_ID"
  }' \
  --output speech.mp3
```

A speech request stays on one voice and model, so it doesn't fail over to a different model.
