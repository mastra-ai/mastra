# Embeddings

```text
POST https://gateway-api.mastra.ai/v1/embeddings
```

Compatible with the OpenAI Embeddings API. `input` accepts a string, an array of strings, or token arrays.

```typescript
const result = await client.embeddings.create({
  model: '__GATEWAY_OPENAI_EMBEDDING_MODEL__',
  input: ['first document', 'second document'],
})

console.log(result.data[0].embedding.length)
```

From a Mastra application, use the model router:

```typescript
import { ModelRouterEmbeddingModel } from '@mastra/core/llm'

const embedder = new ModelRouterEmbeddingModel('mastra/__GATEWAY_OPENAI_EMBEDDING_MODEL__')
```
