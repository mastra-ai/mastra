# Rerank

```text
POST https://gateway-api.mastra.ai/v1/rerank
```

Orders documents by relevance to a query. Use it after retrieval to pick the best context for a prompt.

```bash
curl https://gateway-api.mastra.ai/v1/rerank \
  -H "Authorization: Bearer $MASTRA_GATEWAY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "cohere/rerank-v3.5",
    "query": "capital of France",
    "documents": ["Berlin is in Germany.", "Paris is the capital of France."],
    "top_n": 1
  }'
```

| Field | Description |
| - | - |
| `model` | Required. A rerank model from [`/v1/models`](/docs/gateway/api/models). |
| `query` | Required. The search query. |
| `documents` | Required. 1 to 1,000 non-empty strings. |
| `top_n` | Optional. Number of results to return. Can't exceed the number of documents. |

The response contains `results`, each with the `index` of a document in your request and its `relevance_score`, ordered from most to least relevant.
