# Knowledge

Knowledge is a store of **pages** and **notes** that agents read and write across conversations. A page is a curated topic with a body. A note is a short, attributed fact added to a page. Pages live in **scopes**, such as `org:acme` or `team:acme:support`, and the scope types you declare decide who can read and write each one. The model never picks its own identity or what it can reach.

:::warning

Knowledge is experimental. Its API can change between releases without a deprecation period.

:::

Knowledge attaches directly to an agent and works without [Memory](/docs/memory/overview). With Memory, each run also holds its `resource:` and `thread:` scopes, and [pins](/docs/knowledge/pins) are delivered every turn.

## Quickstart

Declare the scopes your runs hold, turn on the tools, and attach the instance to an agent:

```typescript title="src/mastra/index.ts"
import { Mastra } from '@mastra/core'
import { Agent } from '@mastra/core/agent'
import { Knowledge, knowledgeMemoryScopes } from '@mastra/core/knowledge'
import { LibSQLStore } from '@mastra/libsql'
import { Memory } from '@mastra/memory'

const storage = new LibSQLStore({ id: 'storage', url: 'file:./mastra.db' })

export const knowledge = new Knowledge({
  id: 'company',
  storage,
  scopes: { ...knowledgeMemoryScopes() },
  tools: true,
})

export const agent = new Agent({
  id: 'assistant',
  name: 'Assistant',
  instructions: 'You help the Acme team and keep its knowledge up to date.',
  model: '__GATEWAY_OPENAI_MODEL__',
  memory: new Memory({ storage }),
  knowledge,
  scopes: ['org:acme'],
})

export const mastra = new Mastra({ agents: { agent } })
```

`knowledgeMemoryScopes()` declares `org:$orgId`, `resource:$resourceId` and `thread:$threadId`, and lets each run edit the scopes it holds. Every run of this agent holds `org:acme`, plus its Memory `resource:` and `thread:` scopes:

```typescript
await agent.generate('Our refund window is 30 days. Save that for the team.', {
  memory: { resource: 'dana', thread: 'onboarding' },
})
```

The agent can call `knowledge_page` to create a page in `org:acme`, and any later run that holds `org:acme` finds it with `knowledge_search`.

## Not in this release

Importers, retention and stored per-user grants aren't part of this release. Access is computed from your declarations each time a tool runs, and nothing is stored per user.
