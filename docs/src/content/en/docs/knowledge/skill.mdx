# Knowledge skill guidance

The official `mastra` skill teaches coding agents how to find current Mastra documentation. Knowledge stays inside that existing skill: its always-loaded description and routing table point to `references/knowledge.md`, and that thin reference directs agents to version-matched embedded docs.

Install the official skill with:

```bash
npx skills add mastra-ai/skills --skill mastra
```

Projects created by `create-mastra` install the official skill by default. Pass `--no-skills` only when you intentionally don't want agent guidance installed.

## Embedded docs first

After installing `@mastra/core`, Knowledge guidance is available under `node_modules/@mastra/core/dist/docs/`. Start with these package references:

- `references/docs-knowledge-configuration.md`
- `references/docs-knowledge-access.md`
- `references/docs-knowledge-records.md`
- `references/docs-knowledge-importers.md`
- `references/docs-knowledge-capture.md`
- `references/docs-knowledge-curation.md`
- `references/docs-knowledge-ui.md`
- `references/docs-knowledge-example.md`

These files are generated by Mastra's existing package-doc pipeline from the documentation belonging to the installed package. They match the installed `@mastra/core` version and remain the first authority for coding agents.

If package docs aren't available, the skill routes to the current remote documentation. Remote docs may describe a newer version than the project has installed, so verify final code against local TypeScript types.

## Update the skill

A project keeps the skill version that was installed until you update it. Run:

```bash
npx skills update mastra
```

Skill discovery may refresh at agent turn boundaries. Restart the agent or begin a new turn if an updated reference isn't immediately visible.
