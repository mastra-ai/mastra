# Knowledge instructions

:::warning

Knowledge is experimental and can change without notice.

:::

When Knowledge attaches tools to an agent, it also adds a short instruction block that explains how to use them. Each part is included only when its tools are on:

- **Read:** search with `knowledge_search` before answering, read a page with `knowledge_read` before relying on it, cite the page or note used, say so when nothing is found, and show both notes with their dates when they disagree.
- **Write:** add one durable fact per note with `knowledge_note` on the page it's about, add to an existing page before creating one, put long-form text such as runbooks in a page body with `knowledge_page`, record a change as a new dated note, and remove only notes that are wrong.
- **Pins:** pin only standing instructions, durable preferences and firm constraints that apply without being asked for, keep pinned pages short, and unpin a page once it stops being true.

The text depends only on which tools are on and on your override, never on the run's scopes, its pinned pages or search results, so it doesn't break prompt caching.

## Override the instructions

```typescript
const knowledge = new Knowledge({
  id: 'company',
  storage,
  // instructions: false, to remove the block
  // instructions: 'Your own text', to replace it
  instructions: ({ read, write, pins }) => `${read}\n${write}\n${pins}\nAlways answer in French.`,
})
```

The function receives the default text for each part as `read`, `write` and `pins`, with an empty string for parts that are off. Return the same string for the same inputs, or the prompt cache stops working.

To add the block when you wire tools yourself, call `knowledge.getInstructions({ read: true, write: true, pinnedContext: false })`.
