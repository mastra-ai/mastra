# Knowledge agents and tools

:::warning

Knowledge is experimental and can change without notice.

:::

Set `knowledge` on an agent to give it Knowledge tools. Memory isn't required. Pass the instance, or the key it's registered under on `Mastra`.

```typescript
const agent = new Agent({
  id: 'assistant',
  name: 'Assistant',
  instructions: 'You answer questions about the company.',
  model: '__GATEWAY_OPENAI_MODEL__',
  knowledge,
})
```

## Choose the tools

Set `tools` and `pins` on `Knowledge` to control what an attached agent gets:

```typescript
const knowledge = new Knowledge({
  id: 'company',
  storage,
  tools: { read: true, write: true },
  pins: { maxPins: 20, maxTokens: 500 },
})
```

| Option | Gives the agent | Default |
|---|---|---|
| `tools.read` | `knowledge_search`, `knowledge_read`, `knowledge_browse` | on |
| `tools.write` | `knowledge_create`, `knowledge_append`, `knowledge_remove`, plus node tools such as `knowledge_update_node`, `knowledge_rename_node`, `knowledge_merge_nodes`, and `knowledge_rescope` | off |
| `pins` | `knowledge_pin`, `knowledge_edit_pin`, `knowledge_unpin`, and the pin set in context every turn | off |

Set `pins: true` for the default limit of pins, or pass `maxPins` and `maxTokens`.

## How scopes limit the tools

Every tool takes an optional `scope` argument: a list of tags. The run's own tags bound what the model can name.

- **Reads** search the run's tags plus any `scope` tags. Each extra tag must be held or owned by the run.
- **Writes** land at exactly the `scope` tags when given, otherwise at every tag the run holds. Each tag must be held or owned with write access.
- **Pins** default to every run tag except `thread`.

To wire the tools yourself, for example into an agent's `tools`, call `createTools`. It defaults to the groups configured on the instance:

```typescript
const tools = knowledge.createTools({ write: true })
```

## Memory and pins

Without Memory, pins are shown to the agent on every step. With Memory, pins are saved to the thread, so later steps send only changes.
