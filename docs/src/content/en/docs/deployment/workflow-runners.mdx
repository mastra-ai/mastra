# Workflow runners

Mastra [workflows](/docs/workflows/overview) can be executed using the built-in workflow runner or deployed to specialized workflow execution platforms that handle orchestration, monitoring, and reliability.

## Inngest

Inngest is a developer platform for running background workflows without managing infrastructure. Mastra workflows can be deployed to Inngest, which provides step memoization, automatic retries, real-time monitoring, and suspend/resume capabilities.

Visit the [Inngest deployment guide](/guides/deployment/inngest) for setup instructions and the [Inngest workflow example](https://github.com/mastra-ai/mastra/tree/main/examples/inngest) for a complete implementation.

## Workflow SDK

The [Workflow SDK](https://workflow-sdk.dev) is Vercel's durable execution runtime. With `@mastra/workflow-sdk`, Mastra workflows run inside the Workflow SDK, so steps are durable and replayable, `suspend()` parks on a hook instead of holding a process open, and `.sleep()` survives a deploy.

The engine supports nested workflows, suspend and resume with labels, step scorers, schema validation, tracing, streaming, cancellation, time travel, restart, and the `perStep` execution option. `streamLegacy()` isn't supported because it needs journal introspection the Workflow SDK doesn't expose.

The `@mastra/workflow-sdk` package is experimental and not ready for production use. Visit the [package README](https://github.com/mastra-ai/mastra/tree/main/workflows/workflow-sdk) for setup instructions and a capability matrix against the default engine.

## Temporal

Temporal is a durable execution platform for orchestrating long-running workflows. Mastra workflows can run on Temporal workers, with each `createStep` mapped to a Temporal activity for automatic retries and durable state.

The `@mastra/temporal` package is experimental and not ready for production use. Visit the [Temporal deployment guide](/guides/deployment/temporal) for setup instructions.
