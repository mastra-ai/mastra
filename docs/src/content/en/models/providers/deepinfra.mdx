## Advanced configuration

### Custom headers

```typescript title="src/mastra/agents/my-agent.ts"
const agent = new Agent({
  id: "custom-agent",
  name: "custom-agent",
  model: {
    id: "deepinfra/ByteDance/Seed-2.0-code",
    apiKey: process.env.DEEPINFRA_API_KEY,
    headers: {
      "X-Custom-Header": "value"
    }
  }
});
```

const agent = new Agent({
