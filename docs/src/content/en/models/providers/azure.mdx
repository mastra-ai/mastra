Azure is available through the AI SDK. Install the provider package to use their models with Mastra.

For detailed provider-specific documentation, see the [AI SDK Azure provider docs](https://ai-sdk.dev/providers/ai-sdk-providers/azure).

Azure isn't a model router provider, so model strings like `azure/<model>` don't resolve. Pass a model instance from `@ai-sdk/azure` to the agent's `model` option instead.

The `azure/*` model IDs that can appear in editor autocomplete belong to [LLM Gateway](/models/providers/llmgateway-providers). Use them with the `llmgateway-providers/` prefix, for example `llmgateway-providers/azure/gpt-5.4`. To use your own Azure OpenAI deployments through the model router, register the [Azure OpenAI gateway](/models/gateways/azure-openai).

To use this provider with Mastra agents, see the [Agent Overview documentation](/docs/agents/overview).
