# <img src="https://mastra.ai/brand/logo.svg" alt="Mastra logo" className="inline w-8 h-8 mr-2 align-middle invert dark:invert-0" />Mastra

Mastra Gateway is one OpenAI- and Anthropic-compatible API for models from many providers, with routing, failover, bring-your-own-key, and per-request cost tracking.

Learn more in the [Gateway documentation](/docs/gateway/overview).

## Get an API key

Add credits in **Billing** at [projects.mastra.ai](https://projects.mastra.ai), then create a key in **Gateway** > **API keys**. Keys start with `msk-gateway-`. See the [Quickstart](/docs/gateway/quickstart).

## Usage

Define your API key as an environment variable:

```bash title=".env"
MASTRA_GATEWAY_API_KEY=msk-gateway-...
```

Set a model ID with the `mastra/` prefix:

```typescript title="src/mastra/agents/my-agent.ts"
import { Agent } from "@mastra/core/agent";

const agent = new Agent({
  id: "my-agent",
  name: "My Agent",
  instructions: "You are a helpful assistant",
  model: "mastra/__GATEWAY_OPENAI_MODEL__"
});
```

Use the same prefix for embedding models:

```typescript title="src/mastra/rag/embed.ts"
import { ModelRouterEmbeddingModel } from "@mastra/core/llm";

const embedder = new ModelRouterEmbeddingModel("mastra/__GATEWAY_OPENAI_EMBEDDING_MODEL__");
```

For conversation memory, see [Memory](/docs/memory/overview).
