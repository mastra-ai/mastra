### Agent tools

Give agents tools from Render's hosted Model Context Protocol (MCP) server to create services and datastores, update environment variables, read logs and metrics, and query Postgres databases in Render.

Connect an account with the `render-mcp` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add render-mcp
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/render-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const renderMcpAgent = new Agent({
  id: 'render-mcp-agent',
  name: 'Render agent',
  instructions: 'You help people create services and datastores, update environment variables, read logs and metrics, and query Postgres databases in Render.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['render-mcp'] }),
})
```

Mastra discovers Render's tools from its MCP server when the agent runs. The available tools depend on the server and the connected account, not on your `@mastra/connect` version. Tool keys start with `render-mcp_`.

To see which tools Render provides, read the [Render MCP server](https://render.com/docs/mcp-server) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
