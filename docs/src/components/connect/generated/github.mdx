### Agent tools

Give agents tools to search code and repositories, manage issues, pull requests, branches, files, and releases, and inspect and rerun workflow runs in GitHub.

Connect an account with the `github` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add github
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/github-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const githubAgent = new Agent({
  id: 'github-agent',
  name: 'GitHub agent',
  instructions:
    'You help people search code and repositories, manage issues, pull requests, branches, files, and releases, and inspect and rerun workflow runs in GitHub.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['github'] }),
})
```

The agent gets 49 GitHub tools, with keys such as `github_add_issue_comment`. See [GitHub tools](/reference/connect/providers#github) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
