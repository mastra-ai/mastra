### Agent tools

Give agents tools to send and manage messages, and manage channels, threads, roles, members, and webhooks in Discord.

Connect an account with the `discord` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add discord
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/discord-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const discordAgent = new Agent({
  id: 'discord-agent',
  name: 'Discord agent',
  instructions: 'You help people send and manage messages, and manage channels, threads, roles, members, and webhooks in Discord.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['discord'] }),
})
```

The agent gets 34 Discord tools, with keys such as `discord_add_guild_member_role`. See [Discord tools](/reference/connect/providers#discord) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
