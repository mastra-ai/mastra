### Agent tools

Give agents tools to find, upload, copy, move, and export files, and manage folders, comments, permissions, and shared drives in Google Drive.

Connect an account with the `google-drive` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add google-drive
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/google-drive-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const googleDriveAgent = new Agent({
  id: 'google-drive-agent',
  name: 'Google Drive agent',
  instructions: 'You help people find, upload, copy, move, and export files, and manage folders, comments, permissions, and shared drives in Google Drive.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['google-drive'] }),
})
```

The agent gets 32 Google Drive tools, with keys such as `google_drive_copy_file`. See [Google Drive tools](/reference/connect/providers#google-drive) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
