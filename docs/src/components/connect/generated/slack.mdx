### Agent tools

Give agents tools to read conversations, send and schedule messages, and manage channels in Slack.

Connect an account with the `slack` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add slack
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/slack-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const slackAgent = new Agent({
  id: 'slack-agent',
  name: 'Slack agent',
  instructions:
    'You help people read conversations, send and schedule messages, and manage channels in Slack.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['slack'] }),
})
```

The agent gets 52 Slack tools, with keys such as `slack_add_reaction`. See [Slack tools](/reference/connect/providers#slack) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
