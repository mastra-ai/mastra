### Agent tools

Give agents tools to convert text to speech, transcribe audio and video, clone voices, compose music, manage conversational AI agents, voices and voice settings, and pronunciation dictionaries, and read and delete history items, dubbing projects, conversations, and knowledge-base documents in ElevenLabs.

Connect an account with the `elevenlabs` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add elevenlabs
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/elevenlabs-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const elevenlabsAgent = new Agent({
  id: 'elevenlabs-agent',
  name: 'ElevenLabs agent',
  instructions:
    'You help people convert text to speech, transcribe audio and video, clone voices, compose music, manage conversational AI agents, voices and voice settings, and pronunciation dictionaries, and read and delete history items, dubbing projects, conversations, and knowledge-base documents in ElevenLabs.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['elevenlabs'] }),
})
```

The agent gets 35 ElevenLabs tools, with keys such as `elevenlabs_add_pronunciation_dictionary_rules`. See [ElevenLabs tools](/reference/connect/providers#elevenlabs) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
