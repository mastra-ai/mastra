### Agent tools

Give agents tools to create responses, chat completions, embeddings, images, and moderations, and manage files, batches, and vector stores in OpenAI.

Connect an account with the `openai` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add openai
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/openai-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const openaiAgent = new Agent({
  id: 'openai-agent',
  name: 'OpenAI agent',
  instructions:
    'You help people create responses, chat completions, embeddings, images, and moderations, and manage files, batches, and vector stores in OpenAI.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['openai'] }),
})
```

The agent gets 26 OpenAI tools, with keys such as `openai_add_vector_store_file`. See [OpenAI tools](/reference/connect/providers#openai) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
