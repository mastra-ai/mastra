### Agent tools

Give agents tools from Sentry's hosted Model Context Protocol (MCP) server to search issues and events, read stack traces and traces, and manage issues, projects, and teams in Sentry.

Connect an account with the `sentry-mcp` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add sentry-mcp
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/sentry-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const sentryMcpAgent = new Agent({
  id: 'sentry-mcp-agent',
  name: 'Sentry agent',
  instructions:
    'You help people search issues and events, read stack traces and traces, and manage issues, projects, and teams in Sentry.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['sentry-mcp'] }),
})
```

Mastra discovers Sentry's tools from its MCP server when the agent runs. The available tools depend on the server and the connected account, not on your `@mastra/connect` version. Tool keys start with `sentry-mcp_`.

To see which tools Sentry provides, read the [Sentry MCP server](https://docs.sentry.io/product/sentry-mcp/) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
