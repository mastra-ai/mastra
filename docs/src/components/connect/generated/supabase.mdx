### Agent tools

Give agents tools to query and change table rows, call database functions, and manage storage buckets, files, and auth users in Supabase.

Connect an account with the `supabase` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add supabase
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/supabase-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const supabaseAgent = new Agent({
  id: 'supabase-agent',
  name: 'Supabase agent',
  instructions: 'You help people query and change table rows, call database functions, and manage storage buckets, files, and auth users in Supabase.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['supabase'] }),
})
```

The agent gets 27 Supabase tools, with keys such as `supabase_copy_storage_object`. See [Supabase tools](/reference/connect/providers#supabase) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
