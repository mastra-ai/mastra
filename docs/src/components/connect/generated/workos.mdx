### Agent tools

Give agents tools to manage organizations, users, memberships, invitations, SSO connections, and directories in WorkOS.

Connect an account with the `workos` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add workos
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/workos-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const workosAgent = new Agent({
  id: 'workos-agent',
  name: 'WorkOS agent',
  instructions:
    'You help people manage organizations, users, memberships, invitations, SSO connections, and directories in WorkOS.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['workos'] }),
})
```

The agent gets 40 WorkOS tools, with keys such as `workos_create_connection`. See [WorkOS tools](/reference/connect/providers#workos) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
