### Agent tools

Give agents tools from Neon's hosted Model Context Protocol (MCP) server to manage projects and branches, run SQL, and plan and apply schema migrations in Neon.

Connect an account with the `neon-mcp` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add neon-mcp
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/neon-mcp-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const neonMcpAgent = new Agent({
  id: 'neon-mcp-agent',
  name: 'Neon agent',
  instructions: 'You help people manage projects and branches, run SQL, and plan and apply schema migrations in Neon.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['neon-mcp'] }),
})
```

Mastra discovers Neon's tools from its MCP server when the agent runs. The available tools depend on the server and the connected account, not on your `@mastra/connect` version. Tool keys start with `neon-mcp_`.

To see which tools Neon provides, read the [Neon MCP server](https://neon.com/docs/ai/neon-mcp-server) documentation. To require approval before a call runs, see [MCP providers](/reference/connect/tools#mcp-providers) in the `tools()` reference.
