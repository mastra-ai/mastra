### Agent tools

Give agents tools to read and send channel and chat messages, and manage teams, channels, chats, and members in Microsoft Teams.

Connect an account with the `microsoft-teams` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add microsoft-teams
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/microsoft-teams-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const microsoftTeamsAgent = new Agent({
  id: 'microsoft-teams-agent',
  name: 'Microsoft Teams agent',
  instructions:
    'You help people read and send channel and chat messages, and manage teams, channels, chats, and members in Microsoft Teams.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['microsoft-teams'] }),
})
```

The agent gets 25 Microsoft Teams tools, with keys such as `microsoft_teams_add_team_member`. See [Microsoft Teams tools](/reference/connect/providers#microsoft-teams) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
