### Agent tools

Give agents tools to manage users, organizations, memberships, invitations, roles, and sessions in Clerk.

Connect an account with the `clerk` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add clerk
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/clerk-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const clerkAgent = new Agent({
  id: 'clerk-agent',
  name: 'Clerk agent',
  instructions:
    'You help people manage users, organizations, memberships, invitations, roles, and sessions in Clerk.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['clerk'] }),
})
```

The agent gets 42 Clerk tools, with keys such as `clerk_assign_organization_role_permission`. See [Clerk tools](/reference/connect/providers#clerk) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
