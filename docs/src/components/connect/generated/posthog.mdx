### Agent tools

Give agents tools to capture events, run queries, and manage feature flags, experiments, insights, dashboards, cohorts, and surveys in PostHog.

Connect an account with the `posthog` provider ID. Run this command from the directory that contains your `.env` file:

```bash
mastra connect add posthog
```

Then pass [`tools()`](/reference/connect/tools) to the agent and select the provider:

```typescript title="src/mastra/agents/posthog-agent.ts"
import { Agent } from '@mastra/core/agent'
import { tools } from '@mastra/connect'

export const posthogAgent = new Agent({
  id: 'posthog-agent',
  name: 'PostHog agent',
  instructions: 'You help people capture events, run queries, and manage feature flags, experiments, insights, dashboards, cohorts, and surveys in PostHog.',
  model: '__GATEWAY_OPENAI_MODEL_LUNA__',
  tools: tools({ providers: ['posthog'] }),
})
```

The agent gets 67 PostHog tools, with keys such as `posthog_capture_event`. See [PostHog tools](/reference/connect/providers#posthog) for the full list, and the [`tools()` parameters](/reference/connect/tools#parameters) to restrict tools or require approval before a call runs.
