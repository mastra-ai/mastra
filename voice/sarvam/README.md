# @mastra/voice-sarvam

Mastra Sarvam AI voice integration. Use `@mastra/voice-sarvam` to connect this provider to a Mastra application.

## Installation

```bash
npm install @mastra/voice-sarvam
```

## Usage

Set the API credentials required by your voice provider.

```typescript
import * as packageApi from '@mastra/voice-sarvam';

const availableExports = Object.keys(packageApi);
```
