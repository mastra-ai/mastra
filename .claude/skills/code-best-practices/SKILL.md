# Code Best Practices

Use these guidelines when writing, reviewing, or refactoring code, including tests.

## References

- Read and apply [General principles](references/general/index.md) when implementing or reviewing behavior.
- Read and apply [TypeScript and JavaScript](references/typescript/index.md) for language usage, async operations, performance, and code structure.
- Read and apply [React](references/react/index.md) for components, hooks, and their tests.

For React code, use all three references.

Read the references for the applicable categories, then read their linked rule files in full, including the examples. Apply that guidance when writing, reviewing, or refactoring code.
