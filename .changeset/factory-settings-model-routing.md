Factory settings are grouped by topic: **Account** (My account, Preferences, Connections), **Agent** (Models, Memory, Skills, Behavior) and **Factory** (Repositories, Environment, Work Intake, Manage Factory).

**Models** is now one page. Pick **Personal**, **Hybrid** or **Factory** routing, and a map shows which defaults chats and work-item runs use. Each set of defaults has its own model and providers, and the set the routing does not use folds away. Keys added under Personal defaults are yours; keys added under Factory defaults are shared with the organization and only organization admins can change them.

**Memory** shows personal memory (used by chats) and Factory memory (used by work-item runs) on one page, each laid out top to bottom from messages to the observer and the reflector.

`/login`, `/connect` and the missing-credential screen open the defaults your session runs on: Factory defaults in a Factory-routed Factory, otherwise your personal defaults.

Old links to **Your models** and **Factory memory** open the new Models and Memory pages.
