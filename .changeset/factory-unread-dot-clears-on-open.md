Fixed the Factory sidebar's unread dot not clearing when you open a session. Opening a session now marks its notifications read, so the amber dot on its row goes away and stays away.

A user session whose agent is waiting on you also shows the "Waiting on you" activity indicator that work sessions already had. Its dot clears once you have looked, but the indicator stays while the agent is still parked, so a session that needs an answer keeps saying so.
