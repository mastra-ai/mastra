Runs the Factory starts on its own no longer stall where nobody can see them.

A run that writes a plan used to suspend inside its thread and wait forever: the card said Building, nothing built, and no error appeared anywhere. A new **Plan review** switch on the board decides who answers that pause. On — the default, and what runs already did — the waiting plan surfaces in Needs attention. Off, plans are approved automatically and the run carries the item through to Done.

Three smaller holes on the same path: an agent asking to move its card no longer parks the run behind an approval prompt nobody is watching (the rules engine still governs every move), an item's autonomy now expires at Done or Canceled so re-opened work asks before running again, and a failure that can never succeed on a retry stops burning attempts before it reaches someone.
