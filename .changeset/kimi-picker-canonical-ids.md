Model pickers now list Kimi For Coding, GitHub Copilot and custom provider models under the id you type, such as `kimi-for-coding/k3`, instead of `mastracode/kimi-for-coding/k3`. Typing the id autocompletes to the matching model, and choosing it saves an id that resolves. Previously saved `mastracode/kimi-for-coding/...` and `mastracode/github-copilot/...` ids now resolve too.
