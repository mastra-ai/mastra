Improved the span details panel in Studio traces. Each nested span now opens with a one-sentence summary of what it did, naming the agent, model, tool or processor involved, for example "gpt-5-mini called weatherInfo, then wrote the answer", "Loaded 2 earlier messages from memory into the conversation" or "moderation ran and left the messages unchanged", in a color that matches the result. The sections below are ordered by relevance: spans that change the messages (memory, workspace, skill and processor spans) show those changes inside the summary, then their input, then their output; the root span reads as its input, then its output; the output comes first for nested tool, model and agent spans, and the error for failed spans. A processor that edits the system prompt directly shows exactly which system messages it added or removed. The root span skips the summary unless the run failed or was stopped, since its input and output already say what happened. The Preview, JSON and copy actions of each section now appear when you hover or focus that section. Metadata and attributes are now folded by default on every span and show the raw JSON once opened; a processor's message-list changes appear in their own Changes section in both span layouts.
