Improved the span details panel in Studio traces. Each nested span now opens with a one-sentence summary of what it did, naming the agent, model, tool or processor involved, for example "gpt-5-mini called weatherInfo, then wrote the answer", "Loaded 2 earlier messages from memory into the conversation" or "moderation ran and left the messages unchanged", in a color that matches the result. The sections below are ordered by relevance: the root span and processor spans read as their input, then their output; the output comes first for nested tool, model and agent spans, the message changes for memory, workspace, skill and processor spans, and the error for failed spans. A processor that edits the system prompt directly reads as its input, then its output, then exactly which system messages it added or removed. The root span skips the summary unless the run failed or was stopped, since its input and output already say what happened. The Preview, JSON and copy actions of each section now appear when you hover or focus that section.
