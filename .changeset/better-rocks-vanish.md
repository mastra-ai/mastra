Improved the span details panel in Studio traces. Each nested span now opens with a one-sentence summary of what it did, naming the agent, model, tool or processor involved, for example "gpt-5-mini called weatherInfo, then wrote the answer", "Observational Memory loaded 2 earlier messages from memory into the conversation" or "Moderation left the system prompt and the conversation unchanged", in a color that matches the result. Every span now reads in the same order: what it changed (shown inside the summary for memory, workspace, skill and processor spans), then its input, then its output, then the error, tools, metadata and attributes. A span whose model called tools lists those calls in its summary, each opening on its input and result like in the chat; other spans keep listing the tools that were available. A processor that edits the system prompt directly shows exactly which system messages it added or removed. The root span skips the summary unless the run failed or was stopped, since its input and output already say what happened. The Preview, JSON and copy actions of each section now appear when you hover or focus that section. Metadata and attributes are now folded by default on every span and show the raw JSON once opened. JSON views are no longer clipped behind an Expand button: they open with each top-level value folded, so you see the keys at a glance. An output with nothing to preview, like a model step that only called tools, goes straight to its JSON instead of an empty box; a processor's message-list changes appear in their own Changes section in both span layouts.
