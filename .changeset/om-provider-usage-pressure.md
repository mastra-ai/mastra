Fixed long reasoning-heavy runs outgrowing observational memory's token budget even when their message estimates stayed below it. Observation now also uses the previous step's provider-reported input and output usage, including cached input, with an estimate for newly added content. System messages (including the stored observations) are subtracted, and so is the prompt the provider adds on top of the messages: tool definitions plus anything the provider adds itself, such as Anthropic's tool-use prompt. That added prompt comes from the per-field split the provider reports when it has one (OpenAI Responses), otherwise from the first request of a configuration that replays no reasoning, measured once and reused until the model, tools, tool choice or provider options change. Until it is measured, a local estimate of the tool definitions is used. Between the threshold and `blockAfter` the measurement only buffers or activates, never blocks. Compaction drops the old measurement; missing usage or a changed prompt falls back to message estimates. Messages the model has not read remain protected.
