Sessions linked to a Slack thread can now work across Slack. They can read channels and threads, post messages, search recent messages, find channels and people by name, and send direct messages. Posting needs no approval, so the tools also work on runs nobody is watching.

The tools act as the Slack app, so a session can read and post in any channel the app has been added to, and can DM anyone in the workspace.
