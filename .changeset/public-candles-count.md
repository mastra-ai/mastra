Threads now get a real name on their first turn. Mastra's built-in title generation is enabled for mastracode sessions, so a thread is named from the first exchange with the same cheap model the observational-memory observer uses; the OM observer then refines that title as the conversation grows.

Before, a session kept whatever name it was created with — the raw first prompt, or nothing at all for factory work sessions, which fell back to showing their branch.
