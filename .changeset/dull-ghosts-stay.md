Replaced the raw `buffering`/`observing`/`reflecting` phase label in the Factory status line with two rings, one per memory budget: the message window and the accumulated observations. Each ring shows how full its budget is, and a highlight travels around the ring while memory works through it — background work reads as work instead of leaking an internal phase name. A memory pass that actually holds the turn still says so ("saving memory", "consolidating memory"), and decode throughput now shows a small waveform beside the rate, so a run that is stalling reads as one. Both rings sit in one control, and clicking it opens both budgets in full: an icon each in the budget's own colour, the figures, a bar hatching the slice a pending memory pass will free, and a line saying what reaching the threshold sets off. The control speaks both readings to assistive tech, which a button otherwise hides.

The memory phase is now read from the display state the server sends continuously, not only from the start and end events. A dropped connection during a reflection used to leave the status line claiming memory was still working until some later pass happened to finish; it now settles on the next update. The pending savings figure reads the buffered passes the event stream actually carries, so it stops being permanently blank.

Fixed the throughput figure itself, which was both absurd and mostly absent. It divided a whole step's tokens by the sliver of time between the step's last streamed chunk and its usage report, which could read as `354209 tok/s`. It is now measured on the streamed text over windows of at least 250ms, so it stays in the range a model can actually decode. It also shows up where it used to stay blank: thinking counts as decoding, a run the page joined mid-flight is measured instead of skipped, and the count carries across the messages of one turn. Pauses between steps no longer drag the figure down — a window that spans a tool call is reopened rather than averaged — and a reply the sampler never got to close still gets one reading when the run ends, unless it arrived faster than the sampling floor, where no honest figure exists. The rate keeps its place in the strip even before anything has been measured, so the rest of the line no longer shifts when it appears.
