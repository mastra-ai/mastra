Attention now rides the project feed stream: an automation failure, a proposal parked for approval, an approval, a dismissal, a retry, a supersede or a work-item deletion reaches every open page as it happens, and the attention list falls back to polling only while its stream is down.

Marking your own list read stays local — a read receipt changes nobody else's view, so it is not broadcast.
