Improved experiment comparison in Studio.

- The experiments list no longer leaves you guessing which experiments can be compared. Once you select an experiment, every experiment that ran on the same dataset is highlighted, and a note above the list names that dataset.
- The comparison page now names the compared dataset in its first row, with a link to it. Each experiment header shows the dataset version that experiment ran on, linked to the dataset at that version, and flags it when it differs from the baseline.
