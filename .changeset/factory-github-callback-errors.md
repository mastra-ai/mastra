Factory now explains why connecting GitHub through Mastra Platform didn't work, instead of returning silently to onboarding or settings. If your GitHub account already had the Mastra GitHub App installed, Factory tells you to open Accounts in Mastra Platform and choose Refresh accounts to link it. It also gives plain reasons when you need to sign in to Mastra Platform first, when the link was started for a different account, or when only the GitHub account owner can link the installation.
