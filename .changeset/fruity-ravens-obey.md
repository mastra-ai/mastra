Raised the supported LiveKit Agents and plugin minimum to 1.7.1 so speech flushing and playback outcome APIs are available. Upgrade Agents and its LiveKit and Silero plugins together to 1.7.1 or a matching newer 1.x release.

```sh
npm install @livekit/agents@1.7.1 @livekit/agents-plugin-livekit@1.7.1 @livekit/agents-plugin-silero@1.7.1
```
