
Keyboard shortcuts on the agent page: `R` toggles Run options (Chat composer and Evals row), `A` opens the Attach dataset / Attach scorer combobox on the Datasets and Scorers sub-tabs. Tooltips show the key hint.

"New dataset" / "New scorer" opened from an agent's Evals tab carry `?agentId=`; after creation the app returns to that agent's Datasets / Scorers sub-tab (and attaches the new scorer to the agent) instead of landing on the entity page.

The Experiments sub-tab gets a "Run experiment" action (shortcut `r`) that opens the run dialog with the current agent preselected as target. Run options moves to `u` on every agent tab.
