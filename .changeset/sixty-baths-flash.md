MCP server pages in Studio now show which tools run as MCP tasks (experimental) and list the server's tasks with their status, client, open input requests and expiry. Filter by status, tool or client, load older tasks, or paste a task id to open it. Opening a task shows its result or error, and, with the `mcp:write` permission, lets you cancel it or answer an elicitation it is waiting on.
