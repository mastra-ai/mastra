Knowledge graph explorer page and read-only knowledge routes. The factory API gains project-scoped, read-only knowledge endpoints (entities, facts, activity) with edges derived from wikilinks and an optional validated thread view; the factory web UI gains a Knowledge page rendering the graph with live updates and a detail flyout. Default-schema knowledge capture now requires a short per-fact reason recorded as provenance metadata (custom capture schemas are unchanged).
