Studio breadcrumbs are now visually consistent on every page. Entity crumbs (agents, workflows, tools, scorers, processors, MCP servers, datasets) show the entity name as a plain label or link with a separate chevron switcher next to it, instead of embedding a full dropdown in the crumb. Experiment status icons, workflow run copy buttons, loading skeletons and the Agent Builder title all share the same crumb styling.
