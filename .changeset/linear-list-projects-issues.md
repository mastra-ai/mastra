'@mastra/factory': minor

Factory agents can now browse Linear. `linear_list_projects` lists the connected workspace's projects and teams (optionally filtered by name), and `linear_list_issues` lists the open issues in one of them, with label filtering and pagination. Agents can now read the tickets in a project from its name or URL instead of needing each issue identifier.

The Linear project picker in Settings now lists every project in workspaces with more than 100 projects, instead of only the first 100.
