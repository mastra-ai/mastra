Added mouse support to pickers and slash command suggestions. Click a row in the model picker, `/threads`, `/github`, `/settings`, or another list dialog to choose it. A click does the same as Enter (in multi-choice questions it toggles the checkbox). Click a slash command suggestion to fill it in, scroll with the mouse wheel to move the highlight, and hover to see which row a click will pick. Mastra Code only captures the mouse while a dialog or suggestion list is open, so scrolling back and selecting text in the conversation work as before.
