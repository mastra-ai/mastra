Added mouse support to pickers and slash command suggestions. Click a row in the model picker, `/settings`, or another list dialog to choose it (in multi-choice questions a click toggles the checkbox), click a slash command suggestion to fill it in, scroll with the mouse wheel to move the highlight, and hover to see which row a click will pick. Mastra Code only captures the mouse while a dialog or suggestion list is open, so scrolling back and selecting text in the conversation work as before.
