Traces page: numeric filter operators now read "greater than", "at least", "less than", "at most"; added Environment, End and Total tokens optional columns (Start and End show date and time); added custom columns for any trace property (thread ID, resource ID, entity ID, trace ID) with a header menu that filters the list by a listed value. Column preferences migrate from v2 to v3 without losing existing choices. The "Add metadata column" dialog now lists metadata keys discovered in the selected time range in a searchable combobox, while still accepting a typed key.
