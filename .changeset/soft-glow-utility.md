Added `glow-*` utilities for soft halos. `glow-sm`, `glow-md` and `glow-lg` set the blur, a color utility such as `glow-success-indicator` sets the color, and an opacity modifier such as `glow-md/40` fades it. Without a color, the glow uses the current text color.
