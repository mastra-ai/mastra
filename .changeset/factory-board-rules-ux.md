Factory board settings now show how cards move through a board. **Overview** draws the board as a map: each phase as a column with the rules that bring cards in, the agent that works them, how the work ends and where cards go next, with hover cards for the rules and the skill's instructions. Board columns show the same setup in their header, with an Auto-start switch. The **Rules** page splits into new issues and pull requests, which boards take in intake order, and cards already on the board, and also lists rules on other boards that move cards here. Lanes GitLab never fires are marked GitHub only, and items no board takes now sit at the end of the intake order on **Routing**.
