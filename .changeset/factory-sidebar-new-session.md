Added a **New session** button to the top of the Factory sidebar. It opens an empty session draft, the same as the **+** next to Sessions. Removed the search button on desktop, from the sidebar and from the page header of a collapsed sidebar. Open search with Cmd+K (Ctrl+K on Windows and Linux), with the sidebar open or collapsed. Removed the collapse button from the top of the open sidebar. Collapse the sidebar with its resize handle or `[`. The sidebar toggle still shows in the page header while the sidebar is collapsed.
