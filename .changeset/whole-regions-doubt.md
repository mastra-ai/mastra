OpenCode Zen free models (such as opencode/x-preview-f-free) now run without any API key — pick one in /models and it just works, matching how OpenCode serves its free tier. Paid Zen models unlock by pasting a key via /api-keys or the key dialog (which now opens opencode.ai/auth for you) or by setting OPENCODE_API_KEY.
