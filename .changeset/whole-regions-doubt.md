OpenCode Zen is now a first-class provider with no setup required. Free models (such as opencode/x-preview-f-free) run anonymously without any API key — just pick one in /models or during onboarding. Provider access gained a "free" level, and OpenCode Zen ships as a built-in mode pack and OM pack so the free tier works right after first launch. Paid Zen models unlock by choosing OpenCode Zen in /login, which opens opencode.ai/auth in your browser so you can copy the key, or via OPENCODE_API_KEY.
