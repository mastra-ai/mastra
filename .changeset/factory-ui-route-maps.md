Added a read-only **Map** view next to the intake route and card move editors in the Factory UI.

**Intake routes** (Settings → Intake) shows each route in the order Factory checks it, which one catches every remaining card, and the board and phase each sends new cards to. Pick a source such as GitHub or Linear to see which routes can take its cards, and click a route to open it in the editor.

**Card moves** (a board's Card moves page) shows the board's phases in order, where each phase can send a card next, and which issue or pull request events move cards and where. Hover a phase to trace its moves; click a phase or move to edit it.
