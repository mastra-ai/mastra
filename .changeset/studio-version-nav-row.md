Moved the Mastra version in the Studio sidebar into a regular row next to Settings and Resources. When packages are outdated or deprecated, the row shows an "Update" badge. Clicking it opens a popover instead of a dialog: it lists your installed packages with the versions they update to, and has a copy button for the update command (pnpm, npm, yarn or bun), a button to copy all versions for bug reports, and a link to the changelog.
