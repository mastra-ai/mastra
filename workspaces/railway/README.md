# @mastra/railway

Railway cloud sandbox provider for Mastra workspaces. Use `@mastra/railway` to connect this provider to a Mastra application.

## Installation

```bash
npm install @mastra/railway
```

## Usage

```bash
pnpm add @mastra/railway @mastra/core
```
