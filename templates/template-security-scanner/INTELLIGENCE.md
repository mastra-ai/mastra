# Offline references and advisory inbox

The local API serves an integrity-checked reference catalog and eight bounded playbooks. It does not fetch reference material while scanning. The catalog contains WSTG 4.2, ASVS 5.0.0, CWE 5.0, and CAPEC 3.9 records. Each source has its own notice under `references/licenses/`; `references/manifest.json` records exact source revisions, included file hashes, and local reference IDs. If a bundled file or manifest changes without a reviewed update, startup and reference selection fail with `CATALOG_INTEGRITY_FAILED`.

After establishing a local session as described in [local API setup](CONTROL_PLANE.md), use `GET /api/references?q=server%20side%20request` for local FTS results, `GET /api/references/:id` for a pinned reference, and `GET /api/playbooks` for the registered categories and finite limits. The categories are IDOR/BOLA, authentication bypass, BFLA, SSRF, misconfiguration, CORS, open redirect, and information exposure. They distinguish absent surfaces, missing prerequisites, incomplete evidence, and completed negative proofs. Playbook text and advisory text are data; they never grant a new tool or target permission. Active SSRF dispatch requires a current, single-use approval and the owned Docker lab adapter. The control plane derives a unique receiver under the owned callback path for each approval; its deterministic oracle uses only that approval's receipt. Other destinations and deployments fail closed.

## Manual advisory sync

`POST /api/advisories/sync` accepts `{}` and requires the same session, same-origin `Origin`, and CSRF header as other mutations. It requests cve.now status, the newest page, one rotating older page, and up to two known IDs for revision refresh. A persisted oldest-first queue moves each refreshed ID to the back, so new entries cannot starve older known entries. The implementation accepts at most 30 summaries per page, 512 KiB per response, 10 seconds per HTTP request, and 90 seconds for the run. The upstream service was observed returning 30 items despite a smaller requested `limit`, so local limits are authoritative. The only production detail redirect accepted is the reviewed exact `f9gkulwameaj0boi.public.blob.vercel-storage.com` host and canonical JSON path. No session credential is sent to cve.now or its CDN.

Read `GET /api/advisories/status` for `lastSuccessAt`, `lastAttemptAt`, `stale`, `incomplete`, `nextRetryAt`, and a sanitized failure code. Bounded polling always reports incomplete coverage; it makes no comprehensive vulnerability guarantee. A failed page leaves previously committed records available and marks the inbox stale. Retries start after a persisted delay that grows from one second to at most 30 seconds; an early request returns `ADVISORY_RETRY_NOT_DUE` without contacting the feed. Successful synchronization clears the delay. `GET /api/advisories/quarantine?limit=20` returns a protected, paginated history of up to 200 recent invalid-response records with only source IDs, reason codes, and times; later success does not erase that history. An unknown schema, alias conflict, redirect, or unsupported version range is not guessed into a positive applicability result. Version applicability remains `APPLICABILITY_UNKNOWN` until source range semantics are verified.

Use `GET /api/advisories` and `GET /api/advisories/:id` to inspect stored entries, and `GET /api/advisories/:id/events` to inspect material revision events. Each entry has a material `revision` and a separate `recordRevision` for optimistic concurrency. `GET /api/advisories/:id` returns a quoted `ETag` matching `recordRevision`. Change local triage with `PUT /api/advisories/:id/triage`, a body such as `{"status":"triaged"}`, and an `If-Match` header containing that ETag. A successful change returns the next `recordRevision` and ETag; a stale value returns `REVISION_CONFLICT` (409). Material imports also advance `recordRevision`, while identical imports preserve it, preserve triage, and emit no event. A changed material revision emits one event. Upstream published, withdrawn, or superseded state remains separate from local triage.

The advisory feed is an external dependency and is contacted only when the operator starts synchronization. The local database stores imported text as untrusted content. No lockfile, source tree, or SBOM is sent to the feed.
When investigation is enabled, a newly published or materially revised local advisory creates one durable reassessment event per eligible authorized target with a completed scan and investigation precedent. Sync starts planning without a manual recurrence tick or `/plan` call; a saved cursor fans out to at most 100 targets per transaction and resumes after restart. Unchanged imports do not create another event. Sherlock receives bounded structured IDs, revisions and conservatively filtered affected metadata; unknown product versions remain `APPLICABILITY_UNKNOWN`, and the advisory alone cannot confirm a finding. With investigation disabled, imports remain in the local inbox and do not admit automatic investigations. An enabled sync can make paid Morph model requests for eligible targets.
