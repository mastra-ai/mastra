# Contributing

This template is maintained in the [Mastra monorepo](https://github.com/mastra-ai/mastra/tree/main/templates/template-security-scanner). Accepted changes are synchronized to the standalone template repository.

Make changes in the monorepo and follow its [contribution guidelines](https://github.com/mastra-ai/mastra/blob/main/CONTRIBUTING.md). Run the applicable checks in [testing](https://github.com/mastra-ai/mastra/blob/main/templates/template-security-scanner/docs/testing.md) before submitting a change. Keep operational scripts under `scripts/` and tests and fixtures under `tests/`.
