# Contributing

Make changes in the Mastra monorepo, which synchronizes this template to its standalone repository. [Mastra monorepo](https://github.com/mastra-ai/mastra)

1. Open `templates/template-knowledge-support-agent` in your monorepo checkout.
2. Run `npm install`, then make and test your changes.
3. Open a pull request against the Mastra monorepo. [Template contribution guide](https://github.com/mastra-ai/mastra/tree/main/templates#how-to-add-a-new-template)
