# Contributing

This template is maintained in the [Mastra monorepo](https://github.com/mastra-ai/mastra). The standalone distribution is synchronized from the monorepo.

1. Open `templates/template-knowledge-support-agent` in your monorepo checkout.
2. Run `npm ci`, then make and verify your changes in the template.
3. Open your pull request against the Mastra monorepo. Follow the [monorepo template guide](https://github.com/mastra-ai/mastra/tree/main/templates#how-to-add-a-new-template) for contribution requirements.
