# Square Terminal network checks

Check the network indicator and whether the terminal uses Wi-Fi or Ethernet. Compare the connection with another device on that network. A captive portal network is unsupported. Ask which connection and indicator the technician sees before selecting a diagnostic.

Pending offline payments can be lost by a factory reset. Preserve them and follow [[safety-policy]]. Escalate unresolved connectivity issues to Square Support with a diagnostic report when a reliable connection is available.
