# Square printer connection checks

Original summary of Square guidance, verified 2026-11-20.

Identify the printer model and whether it uses USB, Bluetooth, Wi-Fi, or Ethernet before choosing a diagnostic path. Inspect the device's printer status. Network printers and the device must use the same network.

The example team verifies the printer network and observes a print result before confirming a network mismatch.

Before disruptive account or device changes, check for pending offline payments. Signing out, uninstalling, switching location or mode, or factory resetting can permanently lose those payments.

Source: https://squareup.com/help/us/en/article/5515-printer-troubleshooting
