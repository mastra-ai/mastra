# Square Terminal network checks

Original summary of Square guidance, verified 2026-11-20.

Ask which connection is in use and which connection indicator is visible. For Wi-Fi, check that the terminal is connected to the intended network and compare the connection with another nearby device on that network. For Ethernet, check the cable seating at the Square Terminal Hub and compare with a direct router connection test.

The example team records what changed and the observed result before confirming a diagnosis.

Pending offline payments can be permanently lost by signing out, uninstalling, switching location or mode, or factory resetting. Check their status before proposing changes.

Source: https://squareup.com/help/us/en/article/8350-troubleshoot-network-connection-on-square-terminal
