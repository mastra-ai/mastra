# Local demo

`npm run demo:local` uses mocked support and order data, with responses generated by OpenAI. Every identity, message, order, and result in this guide uses mock data.

Copy `.env.example` to `.env`, set `OPENAI_API_KEY`, keep `APP_MODE=local`, then run `npm run demo:local`. Open the customer demo at `http://127.0.0.1:3000`, support at `http://127.0.0.1:5173`, and Studio at `http://127.0.0.1:4111`.

Sign in as Alex with `alex@example.com` / `local-customer-alex`. Support staff can use `admin@local.test` / `local-admin`; an approver can use `approver@local.test` / `local-approver`. Ask Alex's chat about the USD 5 API Credits purchase on `ORD-1001`, made five days before the demo starts and with no subscription.

Review the case and any proposed refund in the support dashboard. Refunds and next-invoice credits require an authenticated approver's decision.

Each run starts with fresh local demo data. Database paths and signing keys are configured automatically. To change the ports or data locations, see [environment variables](./env-variables.md#local-demo-options).

For verification, run `npm run verify:pre-push`. It checks a clean temporary copy using mocked data and deterministic responses, without an OpenAI key.
