# Contributing

This official template is maintained in the [Mastra monorepo](https://github.com/mastra-ai/mastra/tree/main/templates/template-insurance-policy-checking). Standalone template repositories are synchronized from the monorepo.

Follow the repository's contribution instructions and submit template changes in its `templates/template-insurance-policy-checking` directory. Use synthetic documents for tests. Keep uploaded policies, runtime databases, generated artifacts, credentials and experiment logs out of source control.
