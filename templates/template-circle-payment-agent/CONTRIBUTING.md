# Contributing

This repository is auto-generated from the [Mastra monorepo](https://github.com/mastra-ai/mastra). Pull requests opened here will be ignored.

To contribute:

1. Fork the [Mastra monorepo](https://github.com/mastra-ai/mastra)
2. Find this template in `templates/template-circle-payment-agent`
3. Run `pnpm install` and `pnpm dev` from that directory. The template carries its own
   `pnpm-workspace.yaml`, so it installs on its own rather than as part of the monorepo —
   run both commands from the template directory, not the repository root.
4. Make your changes
5. Open a pull request against the monorepo

A bot syncs accepted changes to this repository.
