# @mastra/isolated-vm

In-process V8 isolate Code Mode transport for Mastra, backed by isolated-vm. Use `@mastra/isolated-vm` to connect this provider to a Mastra application.

## Installation

```bash
npm install @mastra/isolated-vm
```

## Usage

Configure the prerequisites described in the documentation.

```typescript
import * as packageApi from '@mastra/isolated-vm';

const availableExports = Object.keys(packageApi);
```
