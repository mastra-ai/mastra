# @mastra/github-signals

GitHub PR notification signal provider for Mastra agents. Use `@mastra/github-signals` to connect this provider to a Mastra application.

## Installation

```bash
npm install @mastra/github-signals
```

## Usage

Configure the prerequisites described in the documentation.

```typescript
import * as packageApi from '@mastra/github-signals';

const availableExports = Object.keys(packageApi);
```
