# @mastra/codemod

Codemod CLI for Mastra. Install `@mastra/codemod` to use it in your Mastra application.

## Installation

```bash
npm install @mastra/codemod
```

## Usage

Run the v1 migration codemods from the project you want to update.

```bash
npx @mastra/codemod v1
```
