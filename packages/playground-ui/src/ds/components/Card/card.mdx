# Card

`Card` is a raised surface for one piece of content. `CardLink` and `<Card interactive>` make the whole card one click target.

```tsx
import { Card, CardContent, CardDescription, CardLink, CardTitle } from '@mastra/playground-ui/components/Card';
```
