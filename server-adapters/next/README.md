# @mastra/next

Mastra Next.js server adapter — drop your Mastra instance into a Next.js app. Use `@mastra/next` to connect this provider to a Mastra application.

## Installation

```bash
npm install @mastra/next
```

## Usage

Configure the prerequisites described in the documentation.

```typescript
import * as packageApi from '@mastra/next';

const availableExports = Object.keys(packageApi);
```
