# @mastra/server-adapters-test-suite

## 0.2.0

### Minor Changes

- Added `createStructuredWakeTestSuite` to check that idle-thread subscriptions receive structured results and validation errors before the terminal event on plain, durable, and evented agents. ([#28617](https://github.com/mastra-ai/mastra/pull/28617))

  Pass your adapter's scripted model fixture as `setupModel` and its real HTTP server factory as `startServer`:

  ```ts
  import { createStructuredWakeTestSuite } from '@mastra/server-adapters-test-suite';

  createStructuredWakeTestSuite({ setupModel, startServer });
  ```

### Patch Changes

- dependencies updates: ([#28417](https://github.com/mastra-ai/mastra/pull/28417))
  - Updated dependency [`@types/node@22.19.15` ↗︎](https://www.npmjs.com/package/@types/node/v/22.19.15) (from `22.20.5`, in `devDependencies`)

- Add a reusable real-HTTP disconnect suite covering durable and evented stream starts, resumes, tool approvals, observer replay, and explicit cancellation, with ordinary agents as the cancellation control. ([#28162](https://github.com/mastra-ai/mastra/pull/28162))

- Removed the `supportsRBAC` option from the adapter test suite config. Every built-in adapter now enforces route permissions, so the shared "Studio-only RBAC" tests always run. ([#28205](https://github.com/mastra-ai/mastra/pull/28205))

- Server adapters tested with the shared route suite now pass for the MCP server event routes (`/mcp/:serverId/events/:eventName/poll`, `/stream`, `/emit`) and `POST /observability/spans/aggregate`. The suite now registers a test event on its MCP server, supplies the `eventName` path param and an emit payload, runs the dev-only emit route with `MASTRA_DEV` set, and mocks span aggregation support. ([#28116](https://github.com/mastra-ai/mastra/pull/28116))

- Skipped the run-scoped abort route (`POST /agents/:agentId/runs/:runId/abort`) in the generic adapter route suite, since it returns 501 for the suite's non-durable agent by design. Adapter suites no longer fail on this route. ([#28301](https://github.com/mastra-ai/mastra/pull/28301))
